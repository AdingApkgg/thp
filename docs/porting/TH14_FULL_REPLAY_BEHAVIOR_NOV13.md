## 所验证的流程

完整流程从首个声明关卡开始，通过正常 Application 更新连续推进；没有使用跳转将播放直接移到最后一关。26 份输入的关卡顺序、结束菜单、最终分数和资源回收通过检查。咲夜 A 五份连续流程累计 456,935 次 Player 回调；这五份的最终分数另由同一文件的最后一关独立播放核对，其余 21 份在连续流程结束后直接读取最终分数。

141 个游戏提供者和四个宿主提供者从当前源码完整重编；源码与 145 个对象的哈希均已核对。图形使用声明的接口录制边界，音频没有可听输出；没有新增原作素材副本。该记录不代表实际 GPU 画面、浏览器操作、所有录像、任意开局或整作完成。

## 提前结束的原版对照

魔理沙 A Easy 输入 `aec3b304…` 的既有原版进程记录也在第三关提前疮痍。已核对原版输入／归档清单及状态文件身份，并按关卡和 Control 帧比较当前记录的 34,543 个对应边界：所测位置、生命状态、无敌时间、武器、分数、擦弹、点值、火力、残机、碎片、Bomb 和玩家弹数量一致。敌机数量有 60 个关卡入口边界不同，原始差异保留；终态所测玩法和库存一致，分数为 82,434,130。两项内部 RNG 字不同，不作为独立行为门槛，也未覆盖或改写原始结果。

原版记录使用隐藏、静音进程和硬件断点，调试暂停会影响线程时序。本轮没有重新启动原作；该有限对照不能证明其所有可见帧一致，也不能把提前结束改称六关播放通过。其他三个提前结束样本继续核对既有原版记录。

## 查看器进度修复

提前疮痍会打开同一种强制录像结束菜单。旧实现据此把进度拉到当前关卡的声明末尾：上述样本真实停止在累计 34,783 帧，查看器显示 35,775 帧。

C++ 状态接口现在在 GameOver 时返回实际录像游标，正常通关继续包含记录中的结尾尾段；JavaScript 控制器保留原生位置并暂停。游戏更新、碰撞、RNG、残机、分数和录像内容均未改动。

实际共享控制器的四项检查通过，旧版本在 35,775 与 34,783 的比较上失败。当前 Application 加真实线程另验证了该提前疮痍样本的真实游标和原版终态分数，以及咲夜 A Normal 正常六关结束和最终分数。修复尚未部署生产，也未完成此次改动的实际浏览器验收。
