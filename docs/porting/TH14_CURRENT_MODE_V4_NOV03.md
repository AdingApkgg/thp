# TH14 当前核心的 v4 模式复核

对当前玩法 Wasm `f00a33cb…` 的 16 份留存对照重新执行异常、Initialize 时序、Scene 时序和独立原始载荷四项门槛，共检查 1,579,705 次已采集回调。15 份记录通过全部门槛，覆盖 13 个不同自机／难度组合；其中 10 个组合的通过记录包含全部目标关卡入口。同一组合可能有多份记录，自然结束也可能早于六面，不能将记录数当作完整模式数。[结构化结果](th14-current-mode-v4-nov03.json)包含各例来源与门槛收据哈希。

灵梦 B Normal 的 122,537 回调记录通过全部四项门槛，原版实际进入一至六面，所列状态、相机、HUD、303 字动画快照、战斗检查点及初始发布经独立重算相同。这证明该记录的声明范围，不恢复另一个旧 36,826 回调记录中未观察到的线程交错，也不关闭其 RNG 差异。

灵梦 B Easy 的 238,922 回调记录保留先前原始字段相等的结果，但 v4 异常门槛拒绝该记录：原版在第 176,700、176,701、176,702 和 203,400 回调附近报告共 12 次首次机会 C++ 异常，影响尚未证明。因此，旧“16 份通过”的字段比较范围不能自动当作当前四项组合门槛通过。

本轮复用已有原版与模型载荷，没有启动新的原版进程或改动玩法。完整模式、原版普通界面、独立线程调度、整局图像／音频及整作 1:1 继续验收。
