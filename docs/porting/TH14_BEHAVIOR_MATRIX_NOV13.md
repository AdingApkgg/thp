# TH14 自机／难度操作与实际GPU检查 · 2026-11-13

按用户最新的[行为级验收标准](TH14_BEHAVIOR_ACCEPTANCE_NOV13.md)推进，不再要求加载粒子、物理调度或每个像素一致。本轮没有修改生产游戏逻辑，没有补RNG、设置关卡选择或写玩家／库存；输入通过实际普通菜单按键和暂停事件进入当前Application。

## 普通入口和操作

六种自机×Easy／Normal／Hard／Lunatic共24例全部通过。每例实际进入一面，检查选择身份、左移射击产生弹体、低速向右移动且比高速慢、暂停后连续20个外层帧保持Control时钟和Player回调不变、确认恢复后继续更新，以及一次Bomb只扣一个库存并进入效果。六个Normal病例等待各自Bomb控制器完整结束；其他18例只检查触发及后续20帧，不冒充完整Bomb生命周期。

初版夹具把 `life_state=0` 误当成可操作状态，实际等到死亡后才发移动键，失败于“左移”断言。当前生产代码 `PlayerFrame` 的正常活动分支是1。修正夹具后以新目录执行；旧失败、错误断言及退出码保留，没有改变游戏状态机或把原失败标为通过。其他24例没有为挑选启动结果重试。

## Extra

六种自机均通过实际Extra菜单进入七面，再执行上述移动／射击／低速／暂停／Bomb触发检查。为了提供明确的解锁前置条件，独立正常权限组件使用生产 `ScoreFile::initialize/write_records/save/open/read_records` 创建外部测试存档，六种机体的Normal无续关通关记录各为1。运行前把该文件放入各自私有测试目录，未修改正在运行的游戏或真实用户存档。它验证“已解锁存档能正确进入Extra”，不验证通过普通游玩赚取解锁，也不代表六种完整Extra均已验收。

## 实际GPU

当前同一个正常权限145提供者模块另执行六种Normal自机的实际离屏ANGLE/D3D11绘制。逐例经过射击、低速、暂停恢复和完整Bomb控制器；共24份640×480原始帧分别来自射击、暂停、Bomb启动和控制器结束。全部GPU用例通过功能断言并回收实际GPU、线程、音频队列、文件与时钟。

已查看四组拼图：六种自机、射击／弹体、HUD、暂停文字与截图、Bomb效果均有实际画面。部分Bomb控制器结束时仍有动画尾段；咲夜A的瞬时暗色效果另检查结束后120帧，实际画面已恢复正常，记录位于 `gpu-tail-c2-s0-d1-v2`。没有将“控制器active位已清零”直接当作所有动画尾段已结束，也未要求这些帧与原版逐像素相同。
