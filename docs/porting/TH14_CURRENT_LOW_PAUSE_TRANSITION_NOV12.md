# TH14 当前实现的灵梦 B Normal 首次换关对照

当前 `e6b15d27` 实现已在一次真实 C++ Application／线程／ANGLE GLES 运行中通过首个换关后的游戏状态、RNG、弹数和弹 VM 对照。严格 113 字比较仍因继承的相机矩阵缓存而失败。本轮没有改动生产引擎、补随机数或指定加载完成帧。

## 本次结果

新运行自然执行 16,400 次 Player 边界回调、18,428 个宿主帧，随后按预先声明的上限停止并完成线程、GPU、平台和计时请求回收。音乐、音效配置为 0，宿主不输出声音。只运行一次 C++ 前缀，没有启动新的原版进程或复制资产。原版参考来自已结束的 35,000 回调低暂停采集：六字节入口观察器，未附加调试器、运行中不暂停线程。

逐个原始回调比较，32 字游戏状态、HUD 两字及录像游标四字全部相同，共 623,200 字。这里包含 script／visual RNG 种子和计数，以及活跃自机弹数。没有移动回调编号或只选择相等的输入点。

68 个预先声明的输入坐标覆盖一面采样和二面 2142～2146，包含旧首处退弹反例前后。全部槽状态、实测弹字段、SHT 字段、VM 是否存在、所测 VM 字、原版函数重建的 quad 和可见性均一致。对 1057 个捕获弹 VM 进一步比较规范 303 字布局，319,627 个已测字一致。另有 644 个未捕获的原版全局 registry 链接字保持未知，未用零或 C++ 值代替，因此不能称全部 VM／全局 registry 已验收。

## 相机缓存仍不同

严格 113 字前缀为 14,211 回调；从二面输入 1 开始的 2189 行，view／projection 缓存中固定 10 个字段不同。所有非缓存相机字仍相同。失败保留，没有将缓存字段移出门槛。

复用已保留、经校验的原版 helper／真实 Windows x86 D3DX 计算结果，当前 C++ 的整个 128 字节继承缓存有一个逐字相等的有限候选：使用回调 14,074 姿态的 perspective 计算。该原版参考的缓存则匹配 screen 计算。这里没有重新运行 helper，也没有恢复现场复制时间或证明唯一写入者；不能据此强制选择某种缓存或删除正常 perspective 调用。

本轮与旧带调试暂停的六组反例分别记录。上一轮已经证明那些原始输入中的旋转角足以切换完整原版单弹函数的退役分支；本次则确认当前实现到首处反例的自然运行中，游戏状态和所测弹 VM 与低暂停原版一致。两者的采集条件不同，旧失败继续保留，不将它们合并成一次通过。

141 个游戏对象、4 个 SDL／Renderer 对象与当前源码及各自对象绑定重新核验；观察夹具重新编译，包含当前规范 `Application.cpp`。145 个链接提供者按正常访问权限编译；夹具沿用已有的放宽访问权限以读取 Application 私有状态，生产浏览器包没有这个选项。
