# TH14 灵梦 A Bomb 控制器极坐标栈来源

2026-11-01。只修复独立 C++ 实现中已观察到的调用关系；原版坐标、随机数、句柄或逐帧期待值均不输入引擎。

原版控制器 `4138ca` 将二维极坐标临时量未写入的 Z 与玩家 Z 相加，并放入十项历史坐标，之后用于四个碰撞区。先前实现直接使用玩家 Z，因此漏掉同一栈槽上一次调用留下的字。

新增静音原版诊断实际运行 36,826 回调，在预先声明的 Bomb elapsed 18 至 40 窗口观测 23 次读取及 13,027 次栈写入。实际加载模块表确认 32 位 ntdll 的身份；绑定 DLL SHA-256 和导出表后，确认 `RtlLeaveCriticalSection` 的 `push esi` 写入该槽。14 次覆盖层动画尾部路径留下零，7 次普通震屏的脚本 RNG 路径留下其固定对象地址。第一读的先前写入尚未开始观测，单独保留这一限制。另一次回调销毁路径留下动态堆地址，尚未实现。

实现把覆盖层更新、普通震屏 RNG 调用与控制器临时量连接起来，保留原有 RNG 调用次数及回调顺序。回调销毁及未证明的分阶段震屏路径继续暴露未知标记，并保留原有数值回退；不把它们记为一致。23 次读取中 22 次已知字一致，销毁地址一字仍不一致。

隔离候选和正式产物分别重新执行 11 组完整有限回放，每轮合计 1,178,575 回调，全部所选状态、相机、HUD、303 字段活动 VM、战斗检查点和初始发布均严格通过，并独立从原始载荷重算；自然结束及随后 90 次稳定菜单回调保留。两轮通过不等于 11 种完整模式验收。

正式产物的 141 个核心对象全部重编，五个修改文件及全部源码／头文件与候选相同。138 个对象字节相同；其余三个包含 `__FILE__` 诊断路径，全部反汇编指令和偏移逐字相同，仍以新正式产物实际回归为准，不宣称整个 Wasm 二进制相同。

六面 90,012 回调诊断前缀的全部 936 个战斗检查点现已与原版一致：唯一改变是 callback 89,730 的碰撞区 Z。2,021 行 VM 仍保留 script149 的 22 个指针 Z 字差，严格结果依然失败。新增控制器采样还有较早的初始化 RNG 差异；旧核心与新候选的状态／相机／HUD／VM／战斗及初始发布逐字相同，保留该失败，不推定一个交付时刻把它改成通过。

前一 bd70 核心的完整 GLES／WebGPU Application 结果保留版本边界。新核心需要重新验收图形后端及浏览器；普通原版流程、动态地址模型、相机并发、全部模式、整局原版像素／PCM 与独立调度均继续开放。清单仍为 30 个自然结束组合、25 个有全关卡记录的组合，整作 1:1 未完成。
