# TH14 自机对象构造与资源加载

2026-11-11。原版 `44d250` 在调用 `44c4a0` 读取自机动画之前，先分配 `0x184c0` 字节并调用 `44c350` 构造 Player。移植版此前在所选动画上传完成、SHT 读取之后才创建 Player。

初次加载工作线程现先构造私有 Player，对象持有稳定的 SHT 与 ANM 引用；资源加载后在同一个对象上完成初始化和选项生成。等待资源的状态由单独标志记录，已完成或失败的初始化不能被重复准备。主线程仍在加载完成后才接入该对象。

实际 C++ 组件对六种自机分别执行原顺序和提前构造两条路径，使用原包的所选 SHT、ANM 和动画模板。每组的 276 个初始移动、SHT、火力及 RNG 字均相等。组件同时验证资源引用和 Player 分配保持、弹池与道具池仍未提前分配、重复准备被拒绝。最初组件缺少正常启动已有的 ASCII 后备资源，弹幕模板准备失败；补齐前置条件后的完整六组检查通过。

TH12、TH13、TH16 与 TH14 非握手构建的八对预处理翻译单元相同。当前浏览器从源码全量重编 146 个单元，Wasm 为 `32e62384f7c9b3443905068c9e6a7121b1b499309bc107c745d5749cf70f96f7`。组件验证覆盖资源依赖和初始化，原版完整加载时序、首帧 RNG 和整帧像素仍需继续对照，整作 1:1 尚未完成。
