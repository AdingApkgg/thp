## 输入和观察边界

两个私有测试模块以当前普通 Wasm `6b5e86f9…` 为基线，核对全部源码／公共依赖／对象绑定，复用 152 个提供者对象，仅重编 Application。原 Application 只有两处编辑：声明按键提供者，以及把规范化 held 掩码交给该提供者；暂停按键处理、原生 RAF、异步运行时和游戏提供者保留。附加解码器只从原始输入的六字节记录中读取 held 两字节，不恢复录像位置、分数、库存或 RNG，也不调用通关事件。只读观察器记录玩家回调、菜单和实际模式。

Normal 私有 Wasm 为 `812839e6…`；Extra／练习只增加读取菜单／成绩的观察查询，模块为 `a3aa1f79…`。二者均未部署。此前显式调用通关事件的[六结局图形边界测试](TH14_CURRENT_ENDING_GPU_NOV18.md)仍作为独立证据，不能替代本次自然通关。

受控外部启动时钟分别为 Normal／练习 `241224550`、Extra `241201554`；仅替换 `th14_clock_ticks` 导入，不修改 `performance.now` 或游戏 RNG。首个观察到的场景 RNG 与录像进入关卡时的种子属于不同边界，不宣称二者相同。三例实际新录像的关卡头种子分别为 Normal 六关 4607／34382／44160／29215／37947／47628、Extra 35124、练习 4607。

浏览器禁用显示限速、RAF 时间戳乘 8，实际游戏循环与每帧 GPU 路径保留；这是加速功能验收，不是物理实时性能或设备延迟证明。Chrome 全程 `--mute-audio`，三个音量为零，音乐选择 none；音频行为使用既有[混音与真实网页队列证据](TH14_CURRENT_BROWSER_AUDIO_NOV18.md)。

## 保存文件与独立读回

三份新录像均由原版未改动的解密／LZSS 指令解码，并与独立镜像的全部解码字节相等；T14B1 尾部保留。六份写入／新启动成绩各 149,076 解码字节、八条记录校验通过，同样逐字节比较原版指令与镜像。Normal 清关／无续关各 1、结局标志 17 和 Staff 1；Extra 新增清关／无续关各 1 且保留 Normal 排名；练习写入正确的 Normal 第一关练习最高分，全部五难度排名、Normal 解锁及其他五个角色记录保持。未声称原版完整游戏 UI 已加载这些扩展规则文件。

三份实际浏览器录制文件在干净普通 Wasm `6b5e86f9…` 连续结束，分数分别与上表相同，进度无回退，每例 78 个实际代码响应逐字节匹配当前托管包。Extra 擦弹 12,484、练习 3,548 与生产者相同；Normal 的经济状态在进入结局前后重置，未采到对应生产终点擦弹，不作该项相等断言。观看前后角色存档保护通过，只允许原有音乐解锁和校验变化。

Normal 录像结束时 HUD 801,525,760 与经济／录像终分 914,525,760 不同，这是已有[原版终点 HUD 行为](TH14_BEAM_COOKIE_AND_TERMINAL_HUD_OCT23.md)，不可为了同分把 HUD 强行刷新为经济值。后续实际原版 HUD 文件身份也与保留审计相符；相关原版进程入口观察器六字节补丁的范围保持声明，不冒称整个进程未修改。

生产者 Normal 的 116 个、Extra 与练习各 148 个实际代码响应也分别绑定对应私有模块。Normal 六关及结局／Staff／成绩／重启、Extra 四幅和练习四幅，共 18 幅新画面已看；主要对象、背景、HUD、菜单、排名与标题可见。未宣称每个字幕、每个像素或整段历史均相同。

## 复跑与失败保留

测试源码为 `tools/th14-natural-held-input-raf-nov18.cpp.inc`、`tools/th14-natural-held-input-extra-nov18.cpp.inc`，分别按上述两处 sampler 修改附加到匹配 Application，并仅增加 `_th14_acceptance_load_keys`、`_th14_acceptance_natural_state` 导出。保留原编译／链接参数和提供者，不编进公开生产包。三个驱动为 `tools/th14-check-natural-{normal,extra,practice}-gpu-nov18.mjs`，需要 Windows Chrome、可解析的 `playwright-core`、本地合法游戏资源及对应私有预览。

通过 `TH14_FULL_REPLAY_BASE` 指定预览，`TH14_NATURAL_KEYS` 指向哈希匹配的原始输入，`TH14_NATURAL_FRAME_FACTOR=8`；Extra／练习还需 `TH14_NATURAL_SOURCE_SAVE` 指向本次实际 Normal 成绩。固定输入和成绩身份见[机器证据](th14-natural-browser-flows-nov18.json)，原作文件不公开。`--output=` 相对 `artifacts/th14` 指定新的私有目录。公开驱动只调整默认输出位置并删除 Normal 未使用的路径变量，执行版与公开版哈希分别记录；语法检查通过，未以变更输出默认值为由重复整场。

早期手动 tick 测试在线程清理前失败，最终保留原生 RAF；第一次 Normal 完整尝试的采集器因 Node inspector 不支持动态导入退出，不计完成。根目录收集器漏掉 `/save/replay` 的问题由独立回归确认，修正后重新完成 Normal；Extra 第一版菜单驱动漏确认专用难度页；第一次 Extra 消费者用 `.bin` 证据后缀被启动器拒绝，随后只复制相同字节为 `.rpy` 正常导入。原始失败均保留，未据此修改游戏状态或把它们列为生产故障。

本项关闭[行为完成审计](TH14_BEHAVIOR_COMPLETION_AUDIT_NOV18.md)中的当前自然完整 GPU 缺口。其他自机／难度沿用明确的[当前源码复用与补验](TH14_CURRENT_CORE_FLOWS_NOV18.md)，不声称本次同一二进制重跑全部 30 格，也不单凭三例判定整作完成。只有逐项核对八类所需行为、当前交付与残留问题后才审议总目标。
