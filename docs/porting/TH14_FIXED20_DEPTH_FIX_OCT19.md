# TH14 深度换算修正 · 2026-10-19

本次只修改 TH14／version10 分支的片元深度换算，玩法源码保持不变。21 幅记录场景的颜色通道差由 **451 降到 55**，最大差值由 100 降到 **1**；各幅差异均未增加，完全一致的整帧由 3 幅提升至 4 幅。仍未达到整作 1:1。

已安装 D3D9 HAL 的独立实验支持先截断到二十位小数精度，再对 D16 采用最近值、正好居中时向下取值的规则。旧候选单独套用该换算时，世界坐标图像仍然失败，历史结果继续保留；在已经修正整图元视口坐标的当前版本重新测试，较大颜色残差才消失。本次没有按录像帧、像素坐标或深度值填表。

实际生产实现通过 Renderer.cpp 中仅 TH14 编译、仅 version10 执行的着色器源替换接入，共享 Shaders.hpp 保持原字节。当前生产渲染器与四套私有测试模块使用相同 Renderer.cpp。47 组 UV 完整缓冲区哈希全部一致；其中 34 组保留原版完整字节供独立复核，13 组历史参考仅有完整哈希。34 组中的六份历史完整缓冲来自另外两份原版采集，而非当前浏览器服务的原有路由。2,560 个透明裁剪／混合／深度遮挡场景全部一致，915 个独立深度边界输入的实际 D16 读回值全部一致。透明遮挡场景的移植侧保留完整输出哈希，未额外归档其整个输出数组。

146 个 SDL 编译单元全部重新编译，导入和公开导出接口保持。新 WASM SHA-256 为 `58eb0bbfa4363700a53b4ea6a520488b4974d40a8247a9fdf8a82ef45695d38a`，配套加载器和本机站点一并打包。冻结快照相对前版仅 Renderer.cpp 改变，独立 ResourceCrypt 修改排除；旧 30 份玩法输入结果不冒充本次重新执行的整局图形／音频结果。

当前同源预览保持默认静音，四份旧录像保留，普通 Replay 菜单选择灵梦 B Normal 二面后观察实际播放，控制台警告／错误为空；未清理缓存或存档，未把本次短程观察称为浏览器自然 EOF。
