The comparisons cover 31,392 submitted vertices and 941,760 words including geometry, UVs, colors, texture ordinals, filtering/addressing, blend/alpha and combiner state. Draw counts match in every case.

The first raw check fails 31,392 words in 574 cases: every difference is the texture-transform flag, original 2 versus C++ 0. Cases with no submitted vertices have no such difference. The raw failed report remains retained; raw state identity is **not** accepted. For transformed/lit XYZRHW vertices, Direct3D does not apply the texture-coordinate transformation. This follows the [Microsoft Direct3D 9 documentation](https://learn.microsoft.com/en-us/windows/win32/direct3d9/texture-coordinate-transformations). The current GLSL shader also applies it only when vertices are not already transformed.

A separate effective-state check resolves only that flag for XYZRHW vertices. All 648 cases and 941,760 words then match. Negative controls keep the flag active for world-space vertices and reject a one-bit UV change and a blend-factor change. The original raw mismatch is neither deleted nor rewritten as a raw pass. No engine edit is needed to change an ignored state bit.

No game process, GPU run, full replay, pixel acceptance or audible playback is added.
