# TH14 Supervisor 入口与内部资源泵时钟对照

2026-11-05。范围为灵梦 B Normal、同一完整录像的前 35,000 次 Player 回调，经过一至三面。这个有限结果验证比较器的时钟交付缺口，整作 1:1 未完成。

## 观察与故障

静态注册和调用点检查把 Supervisor 优先级 1 的入口确认在 `0x444890`，内部资源泵为 `0x47d720`，Player 为 `0x44dbd0`。在前 1,000 次 Player 发布窗口之后，三个硬件执行断点同时固定保留，第四槽仅在有界窗口观察脚本 RNG，不轮换入口与 pump。实际记录得到各 34,000 条入口、pump、Player；同线程每个已观测 pass 都是入口→pump→Player。新增入口处每个调试异常均有匹配硬件状态，报告调试异常为零。自有并发夹具另验证了省略 Player 的 32 个 pass 仍能观察入口和 pump，因此没有用 Player 计数推导 pass 身份。

原版记录显示，三面 worker 恢复在 Supervisor 入口之后、内部 pump 之前完成。旧比较器在整个 `GameSession.update` 内一直使用入口时间，直到 Player 边界才推进时钟：首读仍使用旧脚本种子，随后在回调 31,009 出现原版三面第 1 帧、模型第 0 帧的差异。

## 同一 Wasm 的启用／禁用对照

诊断构建仅在冻结的 `GameSession.cpp` 内部加载 pump 调用前加入时钟观察钩子；重编 1 个对象，复用 140 个玩法对象。正式玩法源码未改。测试夹具只接收对应 pass 的入口与 pump 时钟，拒绝倒退、错误回调和未完成的交付。无待加载关卡时，调用点不执行并记录为未使用。原版 RNG、矩阵和其他状态值只用于输出比较，不输入引擎。

| 门槛 | 禁用 pump 时钟 | 启用 pump 时钟 |
| --- | --- | --- |
| 既有检查门槛 | 回调 31,009 保留一帧失败 | 全部通过 |
| 32 项逐回调状态 | 失败前脚本种子差 171 次 | 35,000 回调一致 |
| 75 项完整相机字段 | 未完成最终验收 | 34,999 回调／2,624,925 字一致 |
| 原版实际 RNG 指令访问 | 故障审计载荷与旧负例哈希相同 | 64 次值、计数、位置与顺序一致 |
| 动画 VM | 未完成最终验收 | 885 行，每行 303 字及注册顺序一致 |
| 战斗检查点 | 阶段边界断言拒绝 | 502 个一致，其中 49 个非空 |

启用组还通过 HUD、录像游标、启动前 1,000 回调的 3,274 条有序发布以及所有已捕获战斗字段复核。共调度 34,000 个 pump 时钟，其中 453 次在待加载关卡的 pump 处实际交付，33,547 次没有待加载关卡，零交付失败。没有安装额外首次脚本读取等待、Scene 复制交接或上一 Player 代表性入口。模型输出的 68 条脚本 RNG 审计中，64 条对应原版实际指令访问，额外 4 条未接受。

## 保留的限制与失败

这些是调试器接收时间和同线程 pass 内的观测顺序，不是物理帧身份、未受调试影响的执行时间或跨线程精确调度。比较仍按明确声明的原版 worker 完成时间交付；普通独立运行时序、旧默认时钟／争用记录没有因此关闭。未捕获的调用、全模式、普通原版 GUI、原版整局像素／PCM、完整浏览器存档和离线流程继续验收。Scene 严格白名单和所有最终比较断言未改。

首轮长记录在新固定断点启用之前出现 90 秒零 Player 启动超时，原因未证明；终止确认后仅作一次显式重试，重试完成 35,000 回调。旧准备、比较和构建失败均保留，本次通过没有覆盖它们。
