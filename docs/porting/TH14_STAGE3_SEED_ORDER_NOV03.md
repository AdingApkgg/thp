# TH14 三面加载随机数时序诊断

旧的 36,826 回调原版样本中，worker 完成种子写入后、复制全局数据前，主线程停在场景 ANM 更新处。重新检查保留的 512 字节栈和原版调用指令，可确认场景对象循环索引为 6；这份快照没有当时的 VM、目录或 primitive 内存，不能据此断定单个 VM 的身份。四个栈破坏控制均被拒绝。

用原版 `next32` 指令对重放种子 `18535` 做独立运算：worker 事件时内存中观察到的 `10562`、某个隔离实验首个便携种子 `17185`、原版同回调种子 `40379` 分别符合第 4、7、11 次推进。数字相合并不证明这些调用实际发生的次数或跨线程顺序。

将初始化完成时间在测试驱动中假设为较早的 worker Sleep 返回时间后，36,826 回调的所选状态、25 项相机、两项 HUD、360 个战斗检查点和 3,834 条初始发布独立重算相同；538 行 VM 的 303 项对照仍有两处 `worldZ` 不同。原版没有记录当时真实种子写入时间，较早时间只是测试假设，严格验收失败，正式玩法没有采用此时间。

新增独立时间检查器将每个正式 Initialize 时间和保留的原版事件逐项绑定：当前 16 份自然回归均通过，较早假设被拒绝。[有限范围证据](th14-stage3-seed-order-nov03.json)；复核需原版捕获和私有本地产物。
