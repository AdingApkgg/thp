# TH14 原版 HeapFree 返回值观察

在另一个静音原版进程中，按线程将一个硬件执行断点从 CRT 非空释放入口切换到 `HeapFree` 调用返回处；收到返回后恢复入口断点。首次 Player 回调前只做预先声明的暖启动 attract 标志清除，未修改原版指令、随机数、计数或输入。独立的 [600 回调有限记录](th14-heap-free-return-trace-nov03.json)包含 708 次主要分配、130 次清零分配、281 次释放入口及 273 次非空 `HeapFree` 返回；273 次返回的结果均为成功，8 次入口参数为空，结束时没有等待返回的非空释放。音乐及音效主音量实测均为零，未报告调试异常。

按记录的返回交付顺序，273 次成功返回均能与已观察分配配对，其中 89 次跨线程。断点和调试器会改变时序，返回事件的交付顺序不证明系统堆内部的真实操作顺序；附加前状态、未跟踪线程及其他堆路径也未证明。此次不跟踪敌人工厂，32 次 `0x530c` 请求只是同尺寸分配，不能单凭大小认定对象类型。

在这份同一记录上，[隔离模型对照](th14-heap-free-return-model-nov03.json)分别按释放入口和观察到的成功返回交付事件释放合成对象。两种输入的 32 次同尺寸请求重用身份均匹配 27 次，相对首个请求的位置均匹配 1 次；模型未接收原版地址。这只去除了该窗口中非空释放是否成功的假设，仍不能复现原版完整堆、关闭 `worldZ` 差异或证明整作 1:1。
