# TH14 续关 BGM 的计时与跳转 · 2026-10-20

续关恢复 BGM 曾直接保留移植版解码器及其游标。原版 `449e98` 调用完整 `44beb0`，按时钟扣除开始时间和已累计暂停时间，再按原始循环区间折返；恢复时 `481ee0` 把秒数换成截断的采样位置，并减去一个 PCM 帧。解码器预读游标不能替代这套计时。

本次只对 TH14 增加 BGM 开始／暂停／全局挂起计时，保存原版顺序计算的循环秒数，恢复时据此跳转并重建计时基线。其他作品分支保留原逻辑。非正值、不足一个采样帧及不可表示的时间保留旧解码器回退；原版这些输入涉及原始文件偏移下溢，本次没有声称它们一致。

实际验证：

- **216 组原版组件控制，18 首曲目。** 执行完整 `44beb0` 和 `46ac20` 的 QPC 分支、`481ee0` 到 `481f57` 的算术前缀，再分别执行完整 `481b40` 和 `481c40`。QPC、DirectSound Stop、只读文件服务为明确声明的边界；文件读取交付原始 `thbgm.dat` 字节，未播放声音。曲目覆盖循环前、循环尾和多次折返，含暂停／全局时钟偏移。
- **180 组正时间的真实混音器恢复，298,224 个浮点字全部一致。** 使用实际 AudioDevice／miniaudio、无设备 SDL 边界、实际无损 FLAC；通过实际暂停／恢复与挂起／恢复 API 驱动声明的纳秒时钟。保存前只推进少量解码，与保存时钟独立，结果音乐介于保存和恢复之间。恢复 PCM 前缀与上述原版读取字节按 `s16/32768` 归一化后的值逐字一致。尾部读取被原码截短时只比较实际读取的前缀，没有填造循环后的原版字节。
- 在共同声明的 1.25 秒输入下，旧实现 18 首曲目对应 36,864 个浮点字中有 **34,723** 个差异，完整输出实际对应原资源的采样 55,125；原码请求从 55,124 开始。新实现在这 18 组中零差异。这不是对两个真实设备墙钟或实际听感的测量。
- **37 组旧连续播放控制保持通过**，包括全部 cue、两个非零解码前缀、一组循环边界，以及暂停／静音／丢弃／重试。它们的时钟明确冻结为零，验证保留的旧回退和 PCM 连续性；与正时间原版比较分开。另 36 组零时间原码边界未算进一致通过。
- **146 个 SDL 对象全新编译**，WASM `6c1b1877a2dfb4909f9a41a52685d3480f4c153af2a36579476e01e28b2e9e5c`，导入／导出保持，配套加载器字节保持。fixed20 图形、六面名字修复、存档修复和原有私有资源保留。267 个玩法文件未变，既有 30 条完整回放结果没有冒充为新的音频流程验收。独立 ResourceCrypt 修改排除。
- **实际静音浏览器续关两次。** 从普通 Game Start 选择灵梦 A Hard，不改库存或关卡状态，自然 Game Over 后选择续关，再次 Game Over 显示 Credit 3，第二次续关正常返回战斗并暂停，画面显示两颗残机与满火力。当前警告／错误日志为空、音频诊断 `0ms SP`。HTTP 返回模块的完整哈希另行核对；没有实测浏览器波形或同时运行原版 UI 对照，不扩张为所有场景续关均已验证。

[独立复核](th14-music-clock-observed-oct20.json)检查 1,510 个文件绑定，重新读取并归一化原版保留 PCM、重新比较候选输出、核对原始 BGM 文件完整哈希及各读取切片，也确认旧实现的采样位置。命令为 `python tools/th14-music-clock-evidence-check-oct20.py --check`。原始 BGM、解码资源和测试二进制不发布。
