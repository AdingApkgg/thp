# TH14 动画指令间的加载初始化交付

原版加载动画的父脚本 2/17 创建子脚本 2/16 后，worker 可以在子脚本首次更新尚未结束时恢复下一面的 Replay 种子。此前只在首次更新入口轮询，覆盖不到初始化中途的交错。本次在 TH14 实际执行每条 ANM 指令前增加初始化专用轮询；回调只运行已有初始化动作，资源替换仍留在普通资源泵。已有加载器先转入 Hud 阶段，阻止嵌套调用重复初始化。

实现修改 `AnmVm.hpp`、`AnmManager.hpp` 和 `AnmInterpreter.cpp`。生产逻辑没有按自机、脚本、回调序号或种子特判；原版快照、随机数、VM 字段和推进次数均不交付给引擎。
