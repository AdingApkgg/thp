# TH14 背景对象动画边界与录像快照等待

2026-11-04。当前改动已合入七个 C++ 文件；整作 1:1 未完成。

原版 Stage::update_objects 在 40f2a2 调用独立于 ANM8／ANM29 注册链的背景对象 VM，40f2a7 返回。Stage 现在按实际对象、primitive 和 animation 索引传出调用前／返回后边界；Session 在这些位置只轮询 Initialize，不在借用的 Stage 正执行时替换场景或释放资源。

下一关录像初始化的三次 RNG 写入与随后的全局快照恢复分别等待。StageResourceEffects 增加快照 readiness，等待可跨多次更新继续，失败传回 Battle 与 Session；已经完成的 RNG 写入不会重复执行。默认 readiness 仍立即完成，首次录像初始化仍同步，全局快照复制仍作为一个整体操作。

[机器复核收据](th14-stage-object-snapshot-nov04.json)绑定以下有限检查：

- 141 核心对象全新编译；16 份有效留存录像新跑严格通过，共 1,379,760 回调。含 12 次原版首次机会异常的灵梦 B Easy 旧记录继续排除。
- 实测正常动画 VM 身份输入下的一份 35,000 回调记录，所选状态／相机／HUD、1,057 行 VM 的 303 字段与 393 个战斗池检查点相同。
- 实际 Session 中三次 RNG 写入之间分别等待；写入完成后的快照再等待两回调，另有快照失败传播检查。实际背景对象 VM 调用前／返回后失败两项通过；16 项共享编译、7 项无效输入检查通过。
- 静音 Application 两关 2,289 帧／27 断言通过。Application 使用与核心一致的封存头文件，两幅图像及 1,526,784 帧离线 PCM 与上一封存参考一致；物理音频设备打开数零。这不是原版整局像素或音频等价结论。
