旧 10,800 例可以检出重复乘缩放的 45 例，却不能检出漏乘缩放。这个覆盖失败保留在摘要中。新增 5,322 例围绕缩放半径边界取点，预期值由未改写指令的原版 `0x44efa0` 执行产生；命中应用 `0x44f7a0` 是记录身份并返回的受控边界。新增用例分别检出漏乘 729 例、重复乘 589 例。测试位置的公式不充当预期值。

当前夹具使用合成 SHT、玩家位置和状态，复用并核对 145 个提供者对象，没有运行整个 Application，也未声称这些人工边界是自然游玩。旧模块对新增参考同样通过。网页交付源文件的整文件哈希与当前构建收据一致；碰撞和边界函数与 SDK 相同，网页 `collision()` 多出的练习无敌保护明确限定在工具关闭后比较。
