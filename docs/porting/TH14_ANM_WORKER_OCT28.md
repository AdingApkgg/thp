# TH14 初次关卡 ANM 后台解析

2026-10-28。初次关卡加载的 ANM 现由独立 CPU worker 执行生产 `AnmResource::open`，把已解析的纹理、精灵和脚本交给实际 `GameResources::open_anm`，主线程继续准备动画模板并上传 GPU。此前 worker 只解压归档，ANM 的结构验证、精灵 UV 计算及脚本指令转换仍在主线程执行。

只在已有初次资源批次内使用此入口；普通同步读取仍可用。STD、ECL 的解析、自机首次资源及标题加载尚未移入此 worker。没有加入固定帧延迟，没有使用原版 VM、RNG 或像素作为生产输入。这是执行位置的实现推进，尚不能证明跨平台线程调度与原版相同。

## 交付与所有权

`AnmTransferTh14.hpp` 使用显式小端整数字段和浮点位模式，带版本、总长度、来源长度／哈希和负载校验。数据包不传指针、ABI 填充、GPU 句柄、动画模板、时钟或游戏状态。最大包长 128 MiB，集合数量在分配前用剩余字节约束，失败保留目标对象。worker 返回独立转移缓冲；主资源入口只在当前 generation 的回调内取用，结束后清空。

错误批次、损坏数据包及尺寸变化均明确失败，不在失败后悄悄切回同步解析。取消后仍交付一次失效回调，让 C++ 检查 generation 并释放自己的 token；数据不会交给新的资源所有者。CPU 任务不占用主线程的 Asyncify 队列，解析完成后的资源交付仍经过同一队列。
