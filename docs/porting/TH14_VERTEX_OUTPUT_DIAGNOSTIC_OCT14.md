## 实际浏览器输出

在当前真实 shader 的一次绘制中读取了 234 个顶点，每个顶点包含 `gl_Position` 四个字和 UV 两个字，共 5,616 字节。插入观测前后的 21 个颜色缓冲、23 个 UV 缓冲哈希均相同。该控制只能证明本次观测没有改变这些输出；与原版的 880 个颜色通道差异和 5,292 个 UV 字差仍保留。

首版完整 shader 报告超过固定的 2 MiB 接收限制，保存失败。后续使用可逐字恢复的行字典压缩，保留完整私有报告，没有扩大服务器权限或请求体上限。页面只显示短摘要，避免完整转译字符串使页面失去响应。实际摘要页完成 23 个 UV 样本，保存报告与 5,616 字节顶点缓冲，静音标记可见、控制台记录为空；未运行摘要页的颜色模式。

20 种 float32 算术模型中，一种与本次 1,404 个实测输出字一致。这是观测值与模型兼容，不能证明实际硬件指令、原版固定管线的运算方式或通用 shader 改法。

## 两项 Native 对照

| 实际对照 | 完整缓冲结果 | 可支持的结论 |
| --- | --- | --- |
| 原尺寸固定管线与二倍尺寸偶数点采样 | 原尺寸与冻结原版输出零差；二倍尺寸有 4,775 个 UV 字差，覆盖差 0 | 缩放会改变这组输出，后续复制当前 clip 的第三臂按失败门槛未执行 |
| 同一 640×480 尺寸，原固定管线与实测 authored Native clip4 + 当前实际 UV2 | 两臂完整 4,915,200 字节均与冻结原版输出零差；当前浏览器仍有 327 个 UV 字差，覆盖差 0 | 这组实测 authored 坐标在该几何上可重现原版固定管线的完整 UV 输出 |

第二项的 clip4 来自此前实际 authored constant VS2 输出，不是原版固定管线逐属性 clip 的实测。234 个三角形顶点由原始 80 个 strip 顶点展开，逐字附加当前实际 UV2；没有反算偏移、Y 翻转、拟合或替换 clip 为模型值。结果不能唯一归因剩余 WebGL 差异，也不能推出整幅游戏、最终 GPU 指令或整作等价。

2026-10-15 又实际执行两臂 WebGL 坐标传递对照。A 将已测 TF 的 234 个 clip4／UV2 原样上传，输出全部 1,404 个顶点字和 4,915,200 字节像素逐字复现历史浏览器结果。B 将测得的 Native authored VS2 q4 上传，再执行当前 GPU 的 Y 反转及半像素坐标桥接，输出的全部顶点字和像素仍与 A 相同。两臂均保留 Native 的 327 个 UV 字差（U164／V163，164 像素，覆盖差 0）；完整缓冲独占保存，页面静音，捕获警告／错误为空。此 proxy 坐标替换未消除差异，不能唯一归因于光栅、插值或桥接，也不测量原固定管线 clip。[实际两臂收据](th14-render-gap-pass-through-observed-oct15.json)。

同一几何的三角形归属实验随后已实际执行，Native 与 WebGL 各两次绘制，先分别重验完整历史 UV 控制，再以每组三顶点相同的整数 UV 标记三角形。307,200 个像素的覆盖和解码编号完全相同，旧 164 个 UV 差异像素也属于同一批三角形；但完整浮点缓冲仍有 116 个 U 字不同，全落在旧差异区域，最大差约 `2.29e-5`。不能将编号一致写成浮点缓冲逐字一致。[完整归属复核](th14-triangle-ownership-guarded-observed-oct15.json)、[浮点差异收据](th14-triangle-ownership-float-words-observed-oct15.json)。Native 正常路径清理无错误，超时负分支清理未验；浏览器资源清理问题在新副本中修正后才执行，旧准备及失败记录保留。

后续仅做六平面静态分类：差异区域的三角形 71／72／73 在所测 Native authored q4 与实际 GL clip4 中均严格位于裁剪范围内，不跨近／远平面。仅其他两个三角形跨 Y 边界，因此这份输入不支持“差异三角形独有近裁剪”的假设。[裁剪分类及范围](th14-triangle-clip-classification-observed-oct15.json)。

透视属性基随后已实际测量：每组三顶点的 UV 仅改成 `(1,0)、(0,1)、(0,0)`，分别直接输出两组权重，位置、W、拓扑与顺序保留；两端各重验完整历史控制后才执行该臂。完整比较 1,228,800 个浮点字，差异为 U164／V164，共 328 字，全部位于旧 164 个 UV 差异像素及同一三个三角形，覆盖差为零。范围与 U+V 只作分类，不修整原值，也不把和当成独立测得的第三权重。[权重原始缓冲复核](th14-triangle-weights-receipt-oct15.json)。新 Native 夹具清理方法绕过期限检查，正常路径四次实际清理均成功；超时分支仍未实际触发。

三个差异三角形共同使用原始顶点 73。12 种静态视口算术模型对该顶点给出不同的舍入边界分类，但这些模型没有测量硬件视口输出或光栅取整精度，不能据此选定生产修正。[共享顶点的算术范围](th14-shared-vertex-73-viewport-model-oct15.json)。
