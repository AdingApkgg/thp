# TH14 原版种子写入采样与新核心 GLES 回归

对同一录像增加一份静音原版诊断，实际采集 26,000 回调；原版音乐和音效配置及主音量两次读取均为零。worker `456123` 写入脚本种子前和 `456129` 写入后都被捕获；两次快照中主线程停在系统等待代码，没有捕获到场景对象 VM。调试器暂停会影响线程时间，不能由此推断旧样本的线程顺序，也不能把种子写入时刻当作整个初始化完成的已证时刻。

用正式核心 `22c4f853fc1cb81b8a0c0891b88023f2f5dc065e` 对照该样本，分别尝试原版 `456133` 事件时间和 `456129` 事件时间作为完整初始化交付时间。两种输入的已检查输出一致：26,000 回调所选状态、相机、HUD、341 个战斗检查点和 3,835 条初始发布一致，720 行 VM 有七处 `worldZ` 字不同。独立时间校验接受 `456133` 对照，拒绝把 `456129` 当作已证完整初始化；严格通过均为假。

该核心 GLES Application 实际完成 122,622 帧／45 断言并独立复核，每后端所选日志、八幅完整图像／捕获 VM、文件、录像及 89,969,664 帧离线混音与封存参考一致；物理音频设备打开数为零。这是单后端结果，不能算作原版整局像素／PCM 或双后端验收。WebGPU 的沙箱内首次尝试在设备创建时发生访问冲突，失败记录保留；沙箱外设备探针通过后，使用相同构建重跑，截止本报告尚未完成。
