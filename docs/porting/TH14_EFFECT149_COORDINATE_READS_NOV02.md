共 12 组：三种更新速率、两种脚本种子，各给根对象 Z 输入 `0` 和 `0x0d800000`。每组从创建至 120 次后续更新，全部自然退休。内存观察覆盖所有 guest CPU 读写，并按区间重叠过滤；不会漏掉从目标区间之前开始、但覆盖目标字段的宽读取。宿主取快照不计为 CPU 读取。

- 根 Z 并非完全未使用。`4354be` 在父对象位置函数中读取它，经 `4354c6 / 4354f3` 加法参与位置计算，调用方为 `4353bd`。12 组累计 736 次创建后的读取，分别对应 736 次子对象几何调用。
- 在实际几何函数 `4766e0` 的 `476942` 返回点，变换结果的 Z 确实包含所声明的根 Z。随后至该函数返回，CPU 每次都读取临时结果的 X/Y，没有读取其 Z。四个顶点最终 Z 由 `476af3–476b17` 从子对象自身的三个位置字段计算。
- 将相同“不读取”断言移到 X 或 Y 的 24 个控制全部被拒绝。两份已加载原始脚本 149／143 均没有 opcode 64 中断标记；这不能排除任意外部调用。
