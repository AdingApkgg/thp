# TH14 灵梦 Bomb 特效 Z 的真实写入来源

2026-11-01。生产合入五份已测试源文件，完整重编 141 个核心对象。公开构建与隔离候选的 Wasm 逐字相同：`31e86f11380950643cac3f7382c52c2f2a0704f4978836277982c22aa637d287`。

新灵梦 A Easy 原版自然结束样本共 100,311 回调。原核心在第 90,000 回调有 42 个 VM worldZ 字不同。修正后全部样本、983 行／303 字段 VM 重新逐字比较，只剩 script149 的一个 Z 字；41 个修正字分布于脚本 58、145 和 42。原始句柄与注册顺序保持，所选 32 字、25 个相机字、HUD、976 个战斗检查点和初始发布全部相同。严格比较仍退出 1，未将该样本标为通过。

原版 `4144a0` 极坐标辅助函数只写 X／Y，`414020` 随后读取复用栈槽中的 Z。其先前生产者是 `451430` 伤害收集器的几何运算：参考入口对齐 4 时，矩形调用将返回地址 `0x451548` 写入该槽；圆／矩形计算留下旋转后的绝对 X；圆／圆保留先前字。普通命中包装函数还将奖励中点 Y 写入同一槽。生产代码现在按这些真实运算更新显式 ABI 数据，再执行原来的 Z 浮点加法，没有按回调、脚本或原版快照填值。

重新执行原版完整 `451430 → 几何 → 414020` 的 64 组组件，指令未修改，工厂为声明返回边界；栈、地址、位置和初值明确为合成输入。参考对齐 4 的 32 组与实际生产 C++ 的 XYZ、角度、伤害、脚本 RNG 全部一致；旧零 Z 控制失败 20 组。另 32 组不同对齐不作为生产模型通过，未声明任意 ABI 路径等价。旧组件工具曾主动清零极坐标 Z，本次没有沿用其结果覆盖新失败。

修正后的核心另实际严格运行三组完整旧原版载荷，并独立重算：魔理沙 A 80,594 回调／680 行 VM／907 战斗检查点；灵梦 B 122,537／2,586／1,294；Extra 38,403／860／46，全部通过。Extra 包装器旧退出回执误记了普通比较器哈希；真实命令及模型报告均绑定 Extra 比较器，新增勘误保留原回执，不改运行结果。
