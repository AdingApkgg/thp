# TH14 v1.00b 关卡加载与首帧对照

2026-11-11。首关的实际文件读取顺序已经与原版相符。灵梦 B Normal 录像的动画随机数与整帧像素仍有差异，TH14 继续列为进行中。

## 关卡加载

原版在解析主 ECL 的动画声明时，先将文件交给主线程，随后按声明顺序读取子脚本。已占用的动画槽直接复用。原版第一关实测读取顺序为 `st01.ecl → enemy.anm → st01enm.anm → st01menm.anm → default.ecl → st01bs.ecl → st01mbs.ecl`。原版程序的槽检查位于 `422546`，递归加载位于 `422625`。移植版此前先递归加载脚本，又单独读取两份 Boss 脚本，最后才交接动画。

初次开局与换关的 C++ 工作线程现均按 ECL 声明交接动画。七关共完成 49 次文件读取和 19 次动画交接；各关的脚本定义、定义顺序、动画名称和资源数量均与修改前相同。第一关的七项顺序另有实际原版进程记录。测试还覆盖重复声明槽位、拒绝交接、损坏的子脚本以及在同一关卡对象上重试。[逐关计数与哈希](th14-stage-worker-order-nov11.json)

标题阶段还移除了多余的通用敌机、三个默认自机动画和默认脚本预载。六种 Normal 自机组合各运行 120 次 Player 回调，均观察到实际射击。静音浏览器已观察灵梦 B 的 Game Over 重开和返回标题；另一次启动中从标题选择 Quit，正常返回启动页。当前浏览器构建可由启动按钮进入 Normal 演示并显示“运行中”。

## 首帧差异

相同录像和启动配置下，新版第 508 个宿主帧到达第一个 Player 回调，与前一候选的 114 个采样字全部相同。至首次呈现，脚本 RNG 调用次数为 2,588，原版为 2,612。640 × 480 帧缓冲中有 197,624 个像素不同。

原版这次呈现时转场根动画年龄为 85，移植版为 81。背景脚本 195 每次更新将两个纹理坐标各移动约 −0.001，在 256 像素纹理上累计相差约 1.024 个纹素。离线平移比较能解释中央游戏区的大部分高色差，右侧 HUD 还有独立残差。游戏代码和验收比较均保留原始坐标。

## 从源码构建

此构建入口使用 Python 3、带 SDL3 port 的 Emscripten SDK 和源码中的浏览器编译配置。本地验证使用 Emscripten 6.0.10-git。

```sh
python tools/th14-build-gles.py --emsdk /path/to/emsdk --out build/th14
```

输出为 `th14-sdl.mjs`、`th14-sdl.wasm` 及运行时模块，游戏数据由启动器从本机安装提供。构建源码和[编译配置](../../tools/th14-gles-profile.json)随仓库发布。
