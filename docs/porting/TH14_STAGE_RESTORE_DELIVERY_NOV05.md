# TH14 实际加载初始化的独立交付候选

本轮将独立就绪通道接到实际 GameSession 初始化和 SDL 宿主：每次真实 RNG 存储后确认，回放的录像全局投影完成后另确认第四步。开启该路径的 GLES 候选已全量重编 146 个单元（含 141 个玩法单元），真实浏览器完成一次灵梦 B Normal 的普通启动、射击、自然 Game Over、返回标题／Quit 和侧栏管理器检查。

这不是原版独立调度或整作 1:1 通过。普通浏览器这次没有跨关，没有观察到其下一关 Worker 执行。跨关完整回归和额外同步成本仍未验收，严格模式通过数不变。

## 实现与任务边界

`ReplayRngRestoreJobTh14` 增加真实存储完成回调；失败确认会保留已发生的写入、将 job 标为失败并阻止后续存储。旧签名保留原来的立即确认行为，没有改变 RNG 算法、布局或读取保留值。

GameSession 把每次完成交给资源宿主。第三次调用数清零之后，第四次 `stage_replay_snapshot_readiness` 仍可等待；实际经济状态、练习标志、续关数和最小得点投影全部完成，才调用新的全局复制确认。没有提前确认或把第四步合并进第三步。

SDL 的候选路径由 `TH14_STAGE_RESTORE_DELIVERY` 显式启用。真实等待分发后才创建通道；若 incoming owner／battle 尚不存在则失效等待。正常取消和新任务开始会取消旧通道。现有默认预览和用户 8208 页面未替换，本轮独立候选位于本机 8236。

浏览器 Worker 只收到独立控制缓冲区、代次、三步／四步数量和已知的 60 ms 等待下限；不收到 RNG 字、录像帧号、VM 身份或期望结果。C++ 仍执行所有游戏状态写入。每个任务拥有独立缓冲区，旧消息无法操作新任务；取消唤醒等待字并终止 Worker。主线程暂停／后台停顿没有固定两秒失败上限。GLES 与 WebGPU 的回调宿主都安装了通道对象，但只有 GLES 候选本轮完成全构建与有限浏览器运行。

这条通道需要主线程确认后生产下一操作，额外同步成本尚未与原版校准；Wasm 线性内存也没有改为共享内存。不能把它视为三个存储已在独立 Wasm 工作线程物理执行，更不能据此认定 Windows 原版调度等价。

## 已执行的验证

真实浏览器 Worker 入口与生产 client／protocol 通过 Node Worker 外壳执行。同步 Wasm 夹具编译实际 GameSession 初始化 lambda 和实际 `ReplayStageState::restore_economy_th14` 方法体，RNG、恢复 job、经济状态和录像 entry 使用生产类型；battle／图形 owner 是明确声明的合成单元依赖。

12 个用例通过，12 个测试线程均已终结：一次普通记录完成三个存储，三次回放完成三个存储和独立全局复制；至少一次回放确实在第四步等待后才复制。脚本存储后取消、全局复制前取消、拒绝脚本确认、拒绝复制确认和旧代次控制均保持对应的部分状态并失败。拒绝复制确认时实际复制已经发生，没有伪造回滚。另覆盖替换任务后的旧消息、主线程暂停超过两秒、Worker 创建失败，以及不能提前／重复确认。

旧接口夹具另经六例回归；新头文件生成的 Wasm 与前批组件逐字节相同，哈希仍为 `10cc53bf…`，旧观察 scope 路径继续通过。这不是完整玩法回归。

四个成功用例另补查生产者在清理前自然到达完成状态，全部通过；初次 12 例及旧核验器保留，没有覆盖原记录。新候选 146 个对象全部重编，避免虚函数布局改变后混入旧对象。共享作品／WebGPU 五个语法检查退出码均为零；138 条路由的文件哈希、31 个实际 HTTP 请求、契约、模块依赖、隔离响应头和三个 Worker 模块交付检查通过。字体／FLAC 仅建立已存在生成文件的硬链接，数据和大载荷沿用哈希绑定路由，没有重新解包或复制游戏资产。

第一版统计核验器把所有保守冻结头文件都与浏览器快照比较，在未使用的 `Stage.hpp` 上拒绝。失败与旧核验器保留；编译器实际 include 图只有 17 个头文件，这 17 个均与完整候选相同。修正核验范围没有改变原有 Wasm、构建记录或运行结果，也未忽略实际编译依赖。

## 有限普通浏览器结果

新来源通过普通菜单选择 Normal、灵梦及“不使用妖器”的 B 装备，进入第一面并持续射击。自然 Game Over 后，选定终局为 4,560 分、擦弹 14、零残机、三 Bomb、火力 1.00、最大得点 10,010。未续关、未保存／上传／下载录像；正常返回标题后选中并执行 Quit，重新选择作品即可直接打开管理器，完成读取后显示零文件。关闭管理器后侧栏可访问，警告／错误记录为空，全程输出静音，设置未修改。

这些是可见画面与可访问树的操作员观察，没有读取隐藏 Module／文件系统，没有运行整帧像素比较器。第一面自然 Game Over 没有触发下一关，因此浏览器独立交付、实际跨关取消及完整原版录像均继续开放。旧 8210 页没有导航，用户 8208 页面没有操作，也没有重试先前被拒绝的导出。
