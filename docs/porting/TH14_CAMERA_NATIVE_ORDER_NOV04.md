# TH14 原版相机字段顺序修正

2026-11-04：本轮纠正前一版逐字发布中的字段顺序错误，并明确收回原前缀检查的语义映射结论。[机器收据](th14-camera-native-order-nov04.json)，[原版指令位置](th14-camera-native-layout-nov04.json)。

此前 e08d4630 核心按 C++ 结构内存顺序复制，前缀测试也按相同的连续字节种子比较，没有验证复制到的是同名原版字段。原版 target offset 位于偏移 0x48，FOV 位于 0x54，view 矩阵位于 0x60；C++ 把 target offset 放在结构末尾，FOV 和 view 分别位于 0x48、0x4c。原版两个未映射 DWORD 位于 0x58／0x5c，零起始字索引 22／23，并非此前说明中的尾部。旧收据按原样保留，其字段语义覆盖范围由本轮纠正。

当前 Stage 发布按原版顺序映射 73 个已知字，另外保留两个未映射字的进度边界，总计复制前与 75 个步骤后的 76 个边界。没有推断未知字的值或用途，也没有认定它们不影响游戏。没有改变 C++ 相机结构布局、默认无待交付加载时的整结构复制，或向引擎提供原版状态值。

新的组件用按字段偏移初始化的独立测试结构，对照原版 REP 发布、换关 REP 读取及六段原版 ANM 读取指令。76 个前缀各比较 73 个映射字，共 5,548 字，另有 456 次 ANM 原指令读取。上一公开核心在 57 个前缀上出现 557 个语义字错误，76 项进度检查不符；修正版均为零。九个中途失败边界覆盖 target offset、两个未映射字前后及完整复制结尾。测试仅证明所列组件与受控调度，不证明旧原版现场时间。
