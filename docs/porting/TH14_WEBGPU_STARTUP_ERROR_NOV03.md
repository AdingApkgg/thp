# TH14 WebGPU 初始化失败返回

无可用 WebGPU 适配器时，旧浏览器候选的异步初始化会留下未处理的 Promise 拒绝；启动器随后显示首帧超时及资源下载失败。现在初始化拒绝会通知运行时错误处理器，Wasm 桥返回失败，且未创建图形宿主时可以安全清理。并发打开只创建一次宿主、错误只通知一次；成功路径、队列失败传播及边界数组复制均通过组件控制。

同一游戏对象构建的两个独立静音无头 Chrome 记录中，旧版出现一次未处理异常和两种超时，新版显示 `WebGPU initialization failed`，没有这些异常或超时。重新链接复用 146 个相同对象及逐项校验的归档工作线程；Wasm 哈希保持相同，JavaScript 加载器及运行时发生变化。[复核摘要](th14-webgpu-open-error-nov03.json)绑定源码、构建、页面观察及私有截图哈希。

这项验收只覆盖启动失败处理。无头环境未提供 WebGPU 适配器，不能据此验收普通 Chrome 的成功游戏流程、性能、存档或整作 1:1；原有玩法差异继续开放。资源和页面截图保留本机，只公开源码与哈希摘要。
