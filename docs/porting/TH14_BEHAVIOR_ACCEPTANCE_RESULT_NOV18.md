## 保留的差异与边界

原始严格 RNG／相机缓存／句柄、逐像素和逐 PCM 比较失败没有改写为通过。用户已明确取消其独立完成门槛；若未来证明影响玩法、可见音画或稳定性，仍按缺陷处理。

原作魔理沙激光的未初始化 NaN 路径由实际原版现场与指令 Oracle 确认；旧无标录像走原版规则，普通游戏及新录像采用已登记的有限保护并在 T14B 写入规则。其 4,360 分差异明确保留，不声称原版同分；这是一项显式兼容策略，不是未定位的碰撞公式。四个原始提前结束样本、旧不同起始时间线的 Hard 诊断及旧十点差异均保留原结论，未借新输入通关覆写。

本结论不宣称任意随机开局／输入组合均无缺陷，不宣称同一二进制重新执行全部历史测试，不宣称原版完整游戏能播放扩展录像，不宣称每个像素、字幕和设备波形一致。物理触屏／手柄、其他浏览器／设备、无缓存网络条件及未配置的公网 Relay 未扩张为已验收；可选多人保留其独立进行中状态，不并入本次原作单机完成结论。

本次最终补齐的是此前明确缺少的当前自然完整 GPU 完成／保存／新启动及实际新录像干净构建读回；其他七类并非因此自动接受，而是按上表各自直接证据、当前源码变更和反例逐项复核。历史报告中的 `completeGame:false` 保留当时分项范围，不追改。
