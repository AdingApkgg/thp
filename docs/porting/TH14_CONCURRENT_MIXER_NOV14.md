# TH14 当前并发混音 · 2026-11-14

当前实际 AudioDevice／miniaudio 混音器通过四组音乐与单个／多个音效的并发检查，包括 25／50／100 音量、左右声像和十个音效叠加。各个声部独立输出作为输入，按实际输出边界求和并限幅；最大误差 1.20×10⁻⁷，包含 102 个限幅采样。八个缺少音乐或音效的负对照均被拒绝。

两个循环音效的左右声像互换相等；分别暂停音乐或音效时另一方继续，恢复后从保留的游标继续，四组片段比较误差为零。共混合 1,113,560 个立体声帧，实际复用并验证 145 个当前提供者对象，关闭后没有异步错误或残留音频流。

测试只在内存读取 PCM，不连接音频设备，不写出可播放音频，不复制游戏资产。复用已有 18 首 OGG 缓存。本次补足并发、限幅和独立暂停范围，不代替原版 DirectSound 最终 PCM、真实设备、完整浏览器时序或整作验收。

首轮测试将已限幅的多音效总和当作线性参考，第四组被参考前提断言拒绝；失败报告保留。第二轮改为逐声部取未限幅数据，游戏源码未改。[机器摘要](th14-concurrent-mixer-nov14.json)；工具：`tools/th14-check-current-concurrent-mixer-nov14.mjs`。
