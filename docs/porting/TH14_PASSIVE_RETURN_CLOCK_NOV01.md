## 实际观察的边界

两个 worker 窗口共记录 4,380 条边、2,190 对真实调用／返回，每条边只读 1,484 字节 VM。三面恢复 Replay 种子时，主线程实际停在 `47e660` 返回点，返回调试事件尚待送达；活动调用为文件 5／脚本 4。恢复时的只读 VM 身份与调用入口相符，随后返回事件被正确处理。

这一回调观察到的正常 VM 顺序为 `9/35 → 9/36 → 5/2 → 5/3 → 5/4`。模型在注册表入口轮询后第 5 次返回轮询交付时钟，恰为夹具第 6 次访问。检查器核对实际顺序与只交付一次的结果。与此前样本不同，本次直接使用实际返回边界，没有把完成时间推定到整个正常动画注册表入口。

调试事件暂停仍会影响时序；本证据没有证明各条种子写指令与主线程 PC 在同一瞬间的关系，也不验收独立线程调度。
