# TH14 同录像敌人地址布局比较

使用两份已经保留的灵梦 A Easy 原版进程记录，确认来源是同一录像，只比较前 26,000 回调。两份记录有 232 个共同采样回调，其中 211 个关卡和关卡帧也一致。对这些采样，以敌人 `instance` 及所列 31 个战斗字段整体相同、且在各自快照中唯一为配对条件，共得到 14 个回调上的 57 对样本。

这 57 对样本有 15 种地址差值；若以第一对的地址差作为唯一基址平移，只能匹配其中 14 对。因此，一个全局固定平移无法重现这些已匹配字段样本的原版地址关系。[可复算摘要](th14-enemy-address-layout-audit-nov03.json)绑定录像、两份原版报告及战斗快照索引哈希，工具逐份核对压缩快照哈希。篡改快照字节的控制被拒绝。

配对只证明这些采样字段及 `instance` 一致，不能证明跨进程对象的完整生命周期或分配器行为，更不能据此把采样地址灌入移植引擎。地址、原始内存、录像和资源不公开。`worldZ` 指针字差、堆地址／ABI 模型、历史线程顺序及整作 1:1 仍未解决。
