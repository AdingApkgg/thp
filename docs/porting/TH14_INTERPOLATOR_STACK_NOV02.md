# TH14 初始动画的 RGB 与部分字节栈写入

2026-11-02。五份游戏源文件已合入，整作 1:1 未完成。

此前构造首帧的激光临时值只跟踪三维向量插值。继续执行原版 `473af0` 动画插值驱动、读取真实临时字并交给原版 `452700` 激光回调，发现两个额外来源：RGB 速度分支在 `473ef9` 留下更新前的绿色整数，RGB 加速度分支在 `473f47` 留下更新后的绿色整数。三个二维缩放插值使用的正弦辅助函数还在 `4a8038` 执行 `FNSTCW`，只覆盖同一临时字的低两个字节。

实现现按位记录这些独立计算产生的写入。RGB 保留整数原始位；二维插值从已有 PC24／PC64 状态推导 x87 控制字，保留未被该次写入覆盖的其他位。额外缩放和纹理缩放移至旋转插值之前，与原版驱动顺序一致。该顺序会改变最后留下的临时字，即使各个插值自己的数值相同。

只在已证明的 ECL 308 初始动画、首层工厂与随后首层敌人构造路径应用此记录。尚未知的高位仍沿用旧回退，不标为已知；其他写入来源、更深构造调用和真实进程中所有未知高位的来源仍待证明。实现没有输入原版内存、目标帧号、伤害、指针或 RNG 数值。
