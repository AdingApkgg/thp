# TH14 SHT 后台解析与生产消费者

目标仍是独立 C++／Wasm 完整 1:1，仅推进 TH14。本项关闭六份 SHT 仍由调用线程解析原始文件的实现缺口；原版独立调度、普通冷启动 Replay 和整作验收继续，`completeGame=false`、`nativeEquivalent=false`。

## 实现

独立 CPU worker 现在调用原有 `ShtResource` 解析器，再以有版本、有界的 `SHT1` 包传递全部字段。包采用明确的小端整数和浮点位表示，包括 72 个 option 坐标、六个 header 附加字、分组元数据以及每条 ShotSpec 的原生保留字段；不依赖 C++ 对象填充或进程指针。主线程的 `GameResources::open_sht` 只导入解析结果，模板准备和 GPU 工作保留原所有者。

包的上限为 4 MiB，分组不超过原版表的十组；先核对长度、版本、数量、校验和与窄整数规范表示，再构造临时资源。任何失败均保留旧输出。在预取批次里，worker 失败、复制失败或缺少解析结果都会报错，不回退为主线程补读。取消、代数和后续有效批次继续使用现有加载协议。没有活动批次时保留原同步入口，关闭功能的原生构建不包含新传输头。

## 已复算的有限范围

- 六份实际 SHT，60 组、283 条射击配置：全部 header／ShotSpec 字段及规范包字节与实际同步生产解析器一致。四个混合／多资源批次检查独立缓冲所有权，18 次解析结果复制，消费者原始 SHT 读取为零。
- 125 项损坏／失败／取消／恢复控制通过，包括合法校验和下的非法字段、截断、多余数据、复制失败、缺失解析结果、过期批次，以及实际独立 worker 中解析器拒绝损坏输入后恢复。原始 DAT 未改写。
- 实际 `GameSessionResources` 核心所有者的八个有效批次通过：12 次解析 SHT、零次原始 SHT 复制、九次 ANM 和两次 ECL；重复、错误任务、失败、损坏与随后恢复通过。该组件使用声明的包提供服务，不冒称完整 Application 控制器运行。
- 浏览器从冻结 `872da5b` 源码及显式补丁全编 146 个单元，无对象复用。主 Wasm SHA-256 为 `f252f18551418bf1c475c8450718de9337fc7a5cc5bc24f0b88663c975a22fa4`；CPU worker 为 `b1967b96e9d8c5e484c9f008fb3b31b81889dec33a6e48876e7373f4541cae28`。无关的根目录 ResourceCrypt 修改被排除，构建使用冻结生产版本。
- 关闭 worker 的当前 `GameResources.cpp` 重新编译后，对象与此前原生核心逐字节相同，依赖文件中没有 ShtTransfer。此处声明零次新增原生 Application 运行，不把此前两后端的运行次数重新计算。

损坏包测试仅在独立测试端点破坏 `pl00a.sht` 包头，主 Wasm 不变；实际 C++ 在标题前报 `SHT resource pl00a.sht: invalid background SHT transfer`。测试端点服务已停止。正常页面恢复标题和演示后，经普通菜单选择咲夜 B Hard 五面，完成五至六面换关、针妙丸战斗及自然结束；稳定 HUD 为 1,511,063,140 分、残机 1、火力 3.58、点值 305,490、Graze 34,144，与此前冻结流程的所选显示字段一致。随后返回 Replay 列表，整页刷新后管理器再发现一份录像，普通下载的全部 110,306 字节与输入相同。

此运行从五面开始，不继承旧版本从一面开始的整段验收；刷新后没有再次启动游戏列表，故只声称管理器再发现。未核对全程稳定帧率、原版整局图像／音频或内部状态。最终绑定见同目录 [复算摘要](th14-sht-worker-verified-oct29.json)。

## 复算及限制

`tools/th14-sht-worker-check-oct29.mjs` 使用独立 CPU worker 和实际 C++ 资源消费者；`tools/th14-core-tail-worker-check-oct29.mjs` 使用实际核心所有者。`tools/th14-sht-worker-evidence-oct29.py --check` 重新核对源码、构建、对象、组件输出、实际页面回执及私有证据文件的哈希。原作资源、录像、内存、图像、PCM、构建对象与 Wasm 均不发布。

这一改动不测量或关闭原版加载线程的独立交错，不解决原版普通冷 Replay 初始化；没有引入原版 RNG／地址值或固定帧补偿。模式覆盖保持自然记录 30 组、全关入口 25 组。全部模式、整局原版图像／音频、普通物理输入／移动端及整作 1:1 仍待验收。
