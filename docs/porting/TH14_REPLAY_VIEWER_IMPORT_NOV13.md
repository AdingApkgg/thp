# TH14 replay-viewer import · 2026-11-13

The TH14 replay manager initializes its runtime before offering file import. The shell previously rejected every write once launched, so importing a replay through that manager failed with “请先退出游戏” even before selecting a recording for playback. This was reproduced in the real browser using a valid 1,098-byte SHIELD replay saved by the current GameSession after unused-shield expiry and collection of three fragments.

The write command now permits a new replay path only when the title is TH14 and configure explicitly set replayViewer to Boolean true. It still executes the original native file validator and motion validator, writes through the normal FS path and awaits persistent synchronization. An already existing path remains protected while launched. Normal-game writes, score/config imports during play and other titles retain their refusal. Path validation and the existing delete command are unchanged. Active replay readers own their decoded bytes independently of the new file; this does not replace their data or overwrite a current recording.

Twelve cases execute the actual shared shell command/path functions at declared FS/core validation boundaries, and the same twelve execute the actual TH14-specialized candidate. They cover successful new-file forwarding/synchronization, existing-file preservation, ordinary-game refusal, non-Boolean viewer refusal, other-title refusal, score/config paths, native/motion invalidity, empty input, traversal and normal pre-launch import. The frozen pre-fix shell fails the successful new-import case. These boundary checks do not count stub validation results as native format validation. Separately, the SHIELD recording passes original crypto/LZSS instructions and an independent decoder: 899 ordinary input records plus one terminal marker, one stage and no extension.

The candidate changes JavaScript only. Its 146 previously compiled objects and unchanged source bindings are verified, its Wasm hash remains unchanged, and it uses the canonical TH14 shell specialization. Actual browser import/replay and production deployment of this shell change remain pending. See [the qualification JSON](th14-replay-viewer-import-nov13.json). No game data, raw replay or generated module is published. Whole-game acceptance remains incomplete.
