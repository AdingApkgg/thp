# TH14 场景复制时间门槛与 Normal 相机诊断（2026-11-03）

新魔理沙 A Normal 六面记录的基准模型在第二面相机 right.x 上有 16,055 个字差。原版场景复制开始时采到的 right 全为零，复制完成后留下的 right.x 为 `-1.0`；当次没有逐字复制观察，不能仅凭这两个端点判断精确的线程交错。

实验性模型把第二面整个场景交付移到绘制后：107,388 回调的所选状态、相机和 HUD，以及 2,538 行 VM、1,055 个战斗检查点和 2,698 次初始分配的原始载荷复算相等。但这个交付次序没有原版逐字证据，因此是定位实验；不会把它记作原版严格通过，也未修改生产核心。

新增 [Scene 时间门槛](../../tools/th14-verify-native-scene-boundaries-nov03.py)：要求已推进的后续关卡具有原版 `40d435` 复制前事件，模型声明的来源和时间与事件一致，并限制为已审阅的对照驱动。它可以拒绝本次未证实验，但**不能证明复制是原子的、逐字次序正确或独立线程调度已实现**。16 份既有记录的 Scene 时间部分通过，其中一份仍因首次机会异常被独立门槛排除；缺事件／时间变更／错误来源／未审阅驱动四种控制均拒绝。

新的[组合入口](../../tools/th14-verify-native-campaign-exceptions-timing-v4-nov03.py)依次检查异常、活动关卡初始化、Scene 时间和原始载荷。已完成的无异常 66,909 回调正例通过；六面反事实实验在产生 Scene 或原始载荷通过证明前被拒绝。[复核报告](th14-scene-boundary-gate-nov03.json)绑定原始事件、模型及所列反例。后续仍需实际观察该次复制逐字与主线程写入的交错，并解决基准相机差异；不能把匹配的实验结果推广为整局 1:1。
