第一份长采集在 31,064 回调因 `install(other)` 中 `Wow64SetThreadContext` 返回 Windows 错误 5 提前结束；没有调试异常。错误栈、报告及 33 份快照保留，该份未计通过。第二版仅当非当前线程的完整 716 字节上下文完全未变时省略重复写入；必要迁移、待处理 DR6 事件保护和其他 API 错误中止均保留，并增加失败上下文的私人诊断记录。完整 `install()` 的 16 个自有边界用例通过。

两版各自先通过 1,200 回调前检。第二版随后完整完成 35,000 回调，无采集错误或调试异常；实际省略一次不变上下文写入。此结果没有直接证明旧失败当时也是同一种冗余写入，旧失败原因未关闭。
