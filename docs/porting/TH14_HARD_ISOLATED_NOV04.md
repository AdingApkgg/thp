# TH14 魔理沙 A Hard 独立重测

新的静音原版记录完成 114,842 个回调，在同一进程中实际进入一至六面并到达强制录像结束菜单，首次机会调试异常为零。观察器只用硬件断点，未修改指令、输入、RNG 或计数；仅按已声明的暖启动方法清除 attract 位。采样期间停止本会话的电脑 UI 操作，不据此推断所有外部 UI Automation 均不存在，也不据此宣布旧记录的两次异常原因已解决。

本次完整模型对照严格失败。独立重算确认全部 32 项所选状态及 HUD 相同；相机字段 12、13 各有 24,286 个差异，从第 90,557 回调、六面战斗帧 1 开始。VM 和战斗池的比较器报告相等，本记录没有独立重算它们，不能将报告视为整份严格通过。

六面 Scene 相机复制的前后观察都落在第 90,413 回调的 draw 阶段，但复制前读到的源 right 向量与复制后读到的目标向量不同。这将下一步定位收窄到实际复制的内部顺序与写入来源；一个 draw 标签不足以证明精确复制时点，不能为了相机匹配而改写其调度输入。

这份记录证明其声明范围内的六个关卡入口和零调试异常，不证明 Replay 文件 EOF、六面通关、整个模式等价或整作完成。此前相机与 RNG 失败继续保留。
