# TH14 六自机 Normal 普通流程与存档 · 2026-11-14

当前核心来源 `c407a169` 的六种自机均完成一个声明开局时钟的 Normal 普通游戏病例：从真实菜单开始，连续六关、结局、staff、结果和成绩保存；六个全新进程分别读回存档，确认只解锁本次机体的 Extra。不是录像播放模式，没有把录像中的位置、库存、分数、RNG 或完成标志恢复进普通游戏。

## 输入与执行范围

输入提供者解码既有记录并只提供 held 按键与菜单按键。启动时钟为每份输入显式选定，首关及后续关卡记录到的 seed 与输入条件核对；没有在运行中写 RNG 或补抽随机数。输入片段结束时继续射击，不把全 FF 终止标记当作实体按键，也不调用完成关卡的测试入口。

灵梦 A／B、咲夜 A／B 使用已保留的 Normal 输入。原先会提前结束的魔理沙两份输入没有改判；另使用已保留的魔理沙 A `th14_ud07c1.rpy`、魔理沙 B `th14_ud0812.rpy`，原文件和解码身份均核对，没有新下载或复制游戏 DAT。

早期按键夹具在跨关时仍读取上一段，漏掉新关首个移动输入。灵梦 A 的正确首个右下输入未送达，位置从第三关第二帧起偏移，随后自然疮痍。修复只涉及测试按键供给边界，所有旧失败保留，生产游戏源码未改。

活动关卡使用固定逻辑更新批处理；加载和菜单维持实时节奏，已完成资源加载的结局也可批处理。实际 C++ Application、工作线程、关卡和结局解释器及存档路径保持正常运行；图形是声明的接口录制边界，音频没有设备输出。此加速用于功能验证，不是生产游戏帧率或浏览器延迟结论。此次有效病例约 77–129 秒，避免继续为同一种功能验证等待半小时。
