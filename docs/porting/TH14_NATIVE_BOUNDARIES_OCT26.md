# TH14 原版存档与记录结束边界 · 2026-10-26

本轮没有修改生产玩法、图形或音频。当前 SDL 仍为 `11d5c78ceccde1dd07b22cc09e8831cb047f13a724ba7e9b1314e748465109af`，普通浏览器流程尚未验收，整作 1:1 未完成。

实际独立原版进程使用未改动的 EXE/DAT 和私有 APPDATA，观察到标题菜单、自动演示及关闭后写出的 21,633 字节 `scoreth14.dat`。当前生产对象重新链接存档夹具，读取并同步全部记录后重存，完整编码文件逐字节保持一致。另用原版 `456de0`／`456f60` 机器码读写器独立验证全部 149,076 字节角色／设置记录及重写文件；机器码实验仍控制分配、释放和内存复制边界。该证据连接了实际原版文件与当前生产编解码，不代表普通菜单开始游戏、浏览器存档持久化或刷新读回已经通过。

咲夜 A Hard 采集在五面、60,393 个 Player 回调后进程退出，没有观察到结束菜单。此前观察器没有记录进程退出码，其终止标记字段也尚未接入独立观察，旧值 false 不证明检查过该标记。现有日志不能证明退出原因，因此不计入自然结束或六面覆盖。显式诊断前缀独立复算的 60,393 回调通过所选 32 字、相机 25 字、HUD 2 字；六个动画采样共 2,585 行，891 个战斗检查点中 323 个非空，所选字段一致。初始分配顺序只覆盖声明的前 1,000 回调窗口。仍为 **21 组自然结束记录、17 组观察到全部目标关卡入口**。

独立复核工具新增显式 `--prefix` 范围，默认完整记录分支继续要求原版结束菜单。咲夜这份记录未声明前缀时必须失败，已有灵梦 B Normal 完整 122,537 回调仍通过原完整分支。观察器新增原始退出事件的时间、退出码和观察器是否请求终止三个记录；独立 200 回调有界实验确认能记录主动终止产生的退出码 0，同时维持 `observedForcedReplayEndMenu=false`。退出码 0 本身不能作为自然结束条件。

后续观察器将诊断停止与自然菜单结束分开；此前光束诊断分支共用了 complete 标志，本轮未运行该分支，不扩大已有测试范围。未实现的独立录像终止标记改为 null 并显式标明未实现。另可启用主循环退出硬件断点 `469c48`，仅使用加载与初始分配窗口外的空闲槽位，记录退出时的返回值、退出标志和渲染标志；新的同录像采集已在 96,682 回调稳定观察到原版结束菜单，其[完整有限范围对照](TH14_SAKUYAA_HARD_OCT26.md)通过。上次自行退出未复现，原因仍未证明；当前模式清单已更新为 22／18，前段 21／17 为旧批次快照。
