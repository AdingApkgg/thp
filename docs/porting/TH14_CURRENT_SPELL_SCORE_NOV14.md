# 符卡练习成绩的跨启动保存

复用[当前符卡练习流程](TH14_CURRENT_SPELL_FLOW_NOV14.md)已经完成的两份存档：实际普通通关后的原始存档，以及符卡重开、自然失败、返回标题和随后普通开局后的保存文件。本轮不重复游玩或录像，不修改游戏源码及原始存档。

两个独立新进程分别读取前后存档，只推进到标题可操作状态，没有开始游戏，观察加载的全部 149,076 字节成绩记录。两份文件另由未修改原版的解密／解压指令解码，全部字节与新进程所见记录相同。原版指令使用声明的 CRT 边界和零字典；不称为原版游戏进程实测。

灵梦 B 和总表的符卡 ID 3 练习尝试次数均从 0 变为 2，对应初次进入和一次重开；自然失败后练习捕获数保持 0。全部 840 个符卡表项的普通尝试／捕获、练习捕获和最高分保持，仅上述两个表项的练习尝试增加。其他五种自机的完整成绩记录逐字节保持。

前后解码文件只有 8 个字节不同，全部位于所选自机／总表的校验和、练习尝试、开局次数及游玩时间字段。开局次数增加 3，对应两次符卡进入和之后的普通开局；游玩时间增加 711，与写入进程实际 Player 回调数相同。其余排行、六自机通关／练习解锁字段以及整个共享设置记录保持。

本项证明这些声明流程的核心存档写入和跨启动加载，没有接受当前浏览器持久化、所有符卡成功收取或原版完整符卡流程。测试保持静音，图形仍为录制接口，生产运行包不变。
