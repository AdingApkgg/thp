原版实际生成的每个关卡头指针、输入指针和 FPS 指针均转为相对于其解码缓冲的偏移，再与当前生产 `Replay::stage()` 的实际结果逐项比较：关卡号、帧数、载荷大小、头／输入／FPS 偏移全部相同，合计七条。两份完整解码缓冲共 744,698 字节也逐字节一致，没有只查元数据或头部。

两个声明负例只改变新短录像的 magic 或 version 字节。原版普通读取入口均返回失败，当前生产读取器也拒绝；错误返回的数值约定不同，比较的是实际接受／拒绝结果。每个原版负例只读取了 36 字节文件头，没有进入有效载荷读取。未将这种有限负例覆盖称为全部损坏文件行为相同。

当前 C++ 夹具链接逐哈希核对的三个生产对象：Replay、ResourceCrypt 和 Lzss；它们与完整浏览器构建的对应源码绑定一致，工作区另行修改的 ResourceCrypt 未进入本测试。只新增读取夹具／观察工具，没有修改玩法或图形。首次夹具构建因默认临时目录不可写失败，日志保留；将临时目录显式设为该私有用例后正常构建并通过，不改变编译器、对象或接受条件。
