# TH14 当前实现的静音演示画面对照

当前 `e6b15d27` 游戏源码已对照一份保留的无调试器原版 D3D9 画面：第三面自动演示第 1200 帧。1200 回调的原始 113 字、帧末 75 字相机和全部 321 个活动 VM 的数量／注册顺序一致。完整 BGRA 仍有 854 个差异像素，严格画面验收没有通过。

本轮重新编译观察夹具，复用并重新核验当前 141 个游戏对象和 4 个 SDL／Renderer 对象，包含当前规范 `Application.cpp`。145 个链接提供者使用正常访问权限；夹具沿用已有的放宽私有访问以导出帧末状态。生产代码及浏览器构建不变。

一次实际 Application／WASI 线程／ANGLE GLES 运行在 3228 个宿主帧后抵达目标，取得完整画面、全部活动 VM 和相机，随后正常回收 C++ 对象、工作线程、GPU、平台和时钟请求。音乐、音效配置为 0，宿主不发声。原版已在此前的无调试器采集中结束，目标帧之后只执行读回与清理，没有自然退出验收。本轮没有启动原版或复制游戏资产。

## 状态与画面

| 检查 | 当前结果 |
| --- | --- |
| 1200 × 113 字及所有实际录像游标 | 全部相同 |
| 帧末相机 75 字 | 全部相同 |
| VM 数量、句柄集合、完整普通／overlay 注册顺序 | 两侧 321 个，相同 |
| VM 规范布局 | 97,263 个实测字，20 个不同；没有未知链接 |
| 全幅 640 × 480 BGRA | 854 个不同像素，严格失败 |

20 个规范字差异全部来自 file9/script10 的四个灵梦选项动画：年龄 previous／current／fraction、规范布局中重复记录的 current，以及 rotation Z。原版年龄为 1232，当前 C++ 为 1229。使用各 VM 捕获的角速度执行三次 float32 角更新，可以逐位得到原版旋转。该运算解释的是两个冻结状态之间的差值；本次没有重新采集它们的全部出生及调用历史，不能将其写为已直接观察到唯一缺失调用者。

旧同一原版参考与旧 C++ 比较为年龄差 2、817 个差异像素；另一份带选项调用观察器的原版病例则为 808 像素。当前病例独立保留，不用选择某次物理加载结果或写死补帧来匹配。

## 差异范围定位

原版 `479560` 使用保留的原始 VM 与渲染全局数据重建四边形；仅替换旋转 Z 为当前 C++ 的实测角度，再恢复原角度，结果可复现。此项在 Unicorn 中执行，cookie 返回为声明服务，没有改动现场游戏。它不是新的原版 GPU 绘制调用。

第一次范围检查遗漏了中间渲染目标到最终窗口的合成坐标转换，因此把所有差异判在 quad 外；原始工具与结果作为不完整诊断保留。第二版明确使用当前源码的 640 宽视口映射：中间 playfield 从 x=128 移到最终窗口 x=32，声明平移为 `[-96,0]`。旧原版参考没有捕获四个 detached-copy 的实际状态，因此该映射保持组件条件，而非冒充本次原版现场观测。

在整数像素中心条件下，854 个差异中有 816 个落在两侧八个四边形的并集内；其余 38 个的范围为 x=607～612、y=470～477，位于 FPS 末位，保留画面中原版为 60.0、C++ 为 60.1。另保留半像素中心条件下的 801／53 分类，没有选择该分类作为通过标准。范围定位不证明唯一 GPU 因果关系，两个中心条件都没有用作像素排除掩码。

本轮结果支持继续排查加载期实际动画更新的交错和 FPS 时钟呈现。没有补年龄、RNG 或计数，没有延时、强制复制相机缓存或修改裁剪边界。整幅 854 像素及 20 个 VM 字失败继续保留；灵梦 B 手动入口首 Present 的 24 次 SCRIPT 差异、二面缓存、全部模式／普通流程／PCM／存档／公网入口的其他门槛均未因此关闭。
