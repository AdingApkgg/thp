# TH14 3D 条带横向原点 · 2026-11-12

原版 `4783f0` 在 `4785ed` 从 `4f7a88` 读取游戏区横向原点，再把它加入没有父 VM 且设置 `0x60000` 标志的世界矩阵平移。实际有资源的 compositor Begin 在三种显示尺寸下分别设置 320／480／640；C++ 的 `draw_world_strip` 一直固定加 320。修正让这条路径使用当前显示宽度的一半，覆盖绘制模式 23、24 和 effect8 飘带回调。

执行原版未经修改的 `4785ab..478654` 平移前缀，以已执行原版 Begin 的上下文提供原点；与实际 C++ Renderer 公开绘制分派比较。三个宽度、四种标志、两种父 VM 状态、三个非零位置和三条绘制路径共 216 组、3,456 个矩阵字全部相等。相同夹具链接旧代码时有 54 组失败，均为高分辨率下的横向平移字段；640 宽度及无标志／有父 VM 控制保留。

原版的前置缩放／旋转生产、完整绘制回调、材质与 GPU 不属于这个前缀证明；本项使用零旋转与明确给定的非单位缩放，不声称任意游戏区原点、完整像素或整作通过。C++ 实际绘制分派仍执行自身矩阵与材质逻辑，参考输出不输入 C++。夹具最初缺少头文件且误把飘带回调之后合法的屏幕四边形提交视为错误；失败源码和日志保留，修正观察设备后没有改变被测生产路径。

只重新编译一个正常权限提供者，另 140 个源码／对象校验；夹具也使用正常访问权限。TH12／13／16 各一组父版与候选对象逐字节相同。原版进程和新游戏录像均未启动。
