# TH14 三面擦弹边界输入核对 · 2026-11-14

魔理沙 B Lunatic 新通关样本的额外一次擦弹已缩小到三面。本轮采集 393 次尚未擦过弹丸的边界附近查询，其中 196 次返回擦弹；将实际位置、包围盒、已计算的半径、生命周期、无敌及对话状态交给原版 `44efa0`，全部与当前结果相同。原版指令未改写，命中应用为声明边界。
