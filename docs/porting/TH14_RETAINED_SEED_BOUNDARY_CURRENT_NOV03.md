# TH14 留存种子写入边界的当前核心对照

对已有原版灵梦 A Easy 录像前缀重新运行当前 `22c4f853fc1cb81b8a0c0891b88023f2f5dc065e` 核心，未重启原版。该记录有 26,000 次自机回调、两次实际原指令种子写入观察，原版报告没有调试异常。实验使用实际 `456129` 观察时间作为模型中第三面初始化的有限诊断输入，不向引擎传入原版种子或状态。

独立原始载荷复算确认 32 项所选状态、25 个相机字、HUD、291 个战斗检查点及 3,835 次初始发布一致；1,111 行动画中仍有 5 个 `worldZ` 字不同，其中 22,000 回调有 3 个、24,000 回调有 2 个。指针值和原始内存不随源码发布。详见[有限范围核验摘要](th14-retained-seed-boundary-audit-nov03.json)。

`456129` 只观察到一次指令边界，不能证明整个初始化已在该时刻完成；严格初始化时间门槛拒绝这次实验。它不恢复另一个 36,826 回调录像中没有记录的线程顺序，也不消除那份记录的 RNG 差异或动画指针差异，更不证明完整游戏等价。
