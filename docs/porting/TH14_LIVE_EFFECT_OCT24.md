# TH14 存活动画图层与随机角速度 · 2026-10-24

原作两份独立冷启动内存快照在首个Player入口暴露了此前32玩法字未覆盖的差异：effect.anm脚本105的原作图层为2，移植为0；角速度与累计旋转的X/Z值也不同。此前仅比较8项身份和计时字段会漏掉这5项差异。

原作47163b按Z、Y、X顺序解析角速度参数，再存为X、Y、Z。随机引用的取数顺序因此具有意义。TH14解释器现在保留该顺序；其他作品路径保持原有逻辑。原作ECL307/308散动画路径保留复制来的模板图层，移植现在传递保留模板的负层号，避免把脚本105的图层2强制覆盖为0。没有补写随机数、序号、计数器或帧。

修复后，三份独立原作入口样本各71个存活动画的61项比较值全部一致，包含颜色、图层、旋转、角速度、缩放、UV、变量、脚本位置和世界坐标，以及部分重复计时字段；不是61个独立字段，也不代表完整VM或像素等价。首个Player所选32字均一致。两份冷启动控制不写任何原作游戏状态或指令；第三份暖启动仅在未经修改的首个入口快照之后清除一次吸引模式标志。资源上传回调编号与动画更新边界仍不混用。

新核心30组自机／难度回归共2763367个回调与既有逐字节结果一致，各自自然结束并稳定90帧菜单。独立原作完整Extra录像的灵梦A38403、魔理沙B54114、咲夜B50937次回调所选32字仍全部逐字节一致，双方自然结束。

咲夜A Extra完整38977次回调不能算全通过：第15841次起视觉随机数种子及调用计数不同，其余所选玩法字一致。修复前冻结核心和新核心输出整份相同的32字状态流，说明此差异早于本次修改；另一个独立原作窗口再次复现，观察到差值分别为50和98次调用，未用固定补数对齐。正在只读采样其实际ANM调用位置。这项失败与原作Present停滞的排除样本都保留。
