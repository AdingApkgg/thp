## 连续加载对照

原始加载代码从此前保存的共享内存继续，实际读取二面对话 `st02e.msg`、场景 `st02.std`、背景 `st02wl.anm`、时间线 `st02.ecl`。背景全部 1,688,960 字节、ECL 全部 21,244 字节与独立解码文件相同；对话和场景的全部 3,504 字节也已核对一致。

背景有六个 ANM 块。声明的 CPU 贴图模型下，六次显式原版主线程 helper 调用由原码写出 `1→2→3→4→5→6→0`，完成八个模板。当前生产核心使用同一速率和四个 RNG 输入字，比较八个模板的 51 个选定字段、七个精灵描述的 17 个选定字、四个最终 RNG 字，共 531 字，差异为零。指针只在声明的精灵描述字段归一化；没有容差、夹取或生产 RNG 修改。

这些主线程调用仍是 helper 实验，贴图成功属于明确声明的 CPU 模型输入，不能解释为实际 D3D 上传或普通主线程帧续行。资源线程的一次次 1ms 返回也使用声明的相对虚拟截止时间，不是 Native 实际耗时测量。完整工作线程、换关和图像等价仍未完成。
