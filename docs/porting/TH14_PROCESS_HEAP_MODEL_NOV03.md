# TH14 敌人同尺寸堆模型候选

另建独立 WASI 候选，仅模型化合成地址区间内的固定大小分配、相邻空闲块合并、最小可用块选择和同尺寸块按最近释放优先。它没有接入生产游戏，也不接收原版或辅助进程的实际指针。

五种释放顺序分别在三个独立 x86 Windows 辅助进程中运行，共 15 次。每次先分配八个 `0x530c` 字节块，再释放所声明的四个或八个块，并重新分配相同数量。候选模型在 15 次中全部复现辅助进程的相对间距和重用槽位；禁用相邻合并或将同尺寸选择改为 FIFO 的两个控制分别只匹配 6 次。重复释放与虚拟地址溢出控制被拒绝。[有限对照摘要](th14-process-heap-model-nov03.json)只保存槽位和相对间距。

进一步分别在每个敌人尺寸分配前插入 `128`、`4096` 或 `24576` 字节的分配，各运行三个独立 x86 进程，共九次。候选在九次中全部复现被释放的重用槽位，但相对布局只匹配八次；一个 `128` 字节样本的布局不一致。[混合大小反例](th14-process-heap-mixed-nov03.json)不包含实际地址。这是候选模型不适用于所有已测辅助进程布局的直接证据。

这一候选只解释声明范围内的有限样本，不能证明 Windows 堆算法、原版游戏的堆历史或跨进程地址。它不修改生产核心，不关闭 `worldZ` 字差、完整模式或整作 1:1。首次构建因临时文件权限失败、第二次因将链接选项用于编译而失败，失败记录保留；分离编译与链接后成功。
