# TH14 视口量化候选及边界反例 · 2026-10-19

两份视口候选均未采用到生产源码。部分样本改善不等于裁剪与光栅化已完成还原。

在原有二面 frame599／draw47 的 234 个顶点上，五臂实际 WebGL 对照先完整复现当前 TF 和冻结浏览器缓冲，再对全部顶点统一应用视口公式。先乘半视口、再除 W、加半视口并做最近偶数的 8 位子像素量化，能使全部 1,228,800 个 RGBA32F 字与该幅冻结 D3D9 输出一致，消除原来的 327 个 UV 字差。另两种代数等价的 float32 顺序仍有 368 个字差。没有按顶点、三角形编号或像素位置拟合参数。

随后从当前渲染源码复制构建两份独立候选，每份各完成 21 幅完整颜色缓冲和 23 幅 UV／覆盖缓冲对照：

| 候选 | 颜色通道差异总数 | UV 完整哈希一致 |
| --- | ---: | ---: |
| 当前生产控制 | 880 | 20 / 23 |
| 全部世界顶点统一量化 | 492 | 20 / 23 |
| 只对裁剪体内顶点量化 | 807 | 22 / 23 |

第一份候选修好了原先三个 UV 失败样本，却使三面 draw93／94／95 三份原本一致的样本回归。新执行的三次独立 D3D9 HAL 绘制，完整复现这三份原版冻结哈希；生产控制与其全部字节一致，候选分别有 123,682、113,141、190,234 个浮点字不同，覆盖差为零。输入的声明 CPU 分类包含负 W 与跨平面顶点；它用于指导实验，不冒充测得的硬件裁剪坐标。

第二份候选保留了旧版全部 20 份成功 UV 样本，另修正两份；四面的一份仍失败。颜色差异降到 807，逐场景没有新增颜色回归。但独立边界控制给出了反例：预先声明 78 个合成三角形，覆盖近／远／侧平面及负／零 W，不从已知像素残差选择坐标。两次独立 D3D9 绘制先完整复现冻结控制，再取得合成输入的完整原版缓冲。实际 WebGL 候选出现 12 个非有限 TF 位置字；像素缓冲本身有限，但与原版有 282,855 个字差，比不改桥接的 231,558 个字差更多。因此不能仅凭 22 / 23 通过便发布它。

首次边界观察器在有限值检查失败前没有保存候选缓冲；该失败报告保留。随后仅调整观察器的保存顺序，算术与输入不变，复现失败并保存全部三臂 TF／像素缓冲。没有夹取、归一化、替换 NaN 或改写失败值。实际 shader 转译文本也保留，但它不是最终驱动指令，不据此单独归因于驱动或编译器。

该批零 W 控制含六个全零齐次向量，属于特殊退化输入；不能把其中非有限 TF 的结果推广为全部零 W 方向的结论。进一步保持其余声明不变，将这六项改为非零齐次方向 `(0.0625,-0.03125,0,0)`，再次完成独立 D3D9 控制和实际 WebGL 对照。所有 TF／像素字均有限，旧桥接仍为零覆盖差，候选却新增 `(18,61)`、`(171,314)` 两个覆盖像素；完整浮点字差从 194,071 增为 230,520。这在排除全零向量因素后，仍然反证了当前候选的普适性。没有根据输出选择方向参数，也没有把像素回归改为容差通过。

独立检查器 [th14-viewport-candidate-evidence-check-oct19.py](../../tools/th14-viewport-candidate-evidence-check-oct19.py) 复核 212 项绑定、所有颜色缓冲、全部 UV 哈希及可取得原版完整字节的 10 份 UV 缓冲，并重新核对边界失败的所有原始字。证据检查通过，候选验收失败。检查器不启动游戏、编译器、GPU、浏览器或音频设备；私有结果为 `artifacts/th14/viewport-candidates-audited-v2-oct19.json`。V1 最终 JSON 复核中的 tuple／list 表示问题、原工具及失败记录保留；V2 使用 JSON 原生列表并重新核验。原版资源、二进制和像素采集不公开。

补充的 [非零齐次边界检查器](../../tools/th14-viewport-valid-boundary-evidence-check-oct19.py) 按完整缓冲复核上述有效方向控制，19 项绑定及 `--write`／`--check` 均通过；A 仍与它自己的冻结控制比较，B／C 才比较合成 Native 缓冲。私有结果为 `artifacts/th14/viewport-boundary-valid-w-v2-oct19/independent-comparison-v2.json`，此前包含无关 A／合成几何覆盖索引的 V1 报告与工具仍保留。

下一步需要保留齐次裁剪与视口量化的实际顺序，增加独立边界控制，不能按场景编号切换公式或回填单个拟合坐标。当前生产 Shader 与已发布版本完全相同；整作 1:1 未完成。
