## 首个实际游戏帧的因果控制

新原版观察补齐 ECL 自己的 ANM 加载路径：`422565` 进入 CPU 加载，`42257a` 发布 GPU 任务，`422599` 退出上传等待。该路径直接调用 `47cff0`，不经过旧观察器覆盖的 `47d0ec`。file 10 上传结束后，worker 才进入 file 11 的 CPU 加载；本次 file 11 CPU 加载跨过三次 Present。观察使用硬件执行断点，会扰动线程调度，不能把次数当作通用固定延迟。
