# TH14 线性雾效算术修正 · 2026-10-20

仅 TH14／version10 的线性、非距离雾路径采用实测顺序：CPU 以 float32 逐项合成 View × World，计算 `scale = 1 / (far - near)`、`bias = far * scale`，顶点使用 `bias - abs(eyeZ) * scale`。顶点不先饱和，片元插值后仍由原有片元路径限制到 0–1。其他雾模式、共享着色器头及玩法／声音／存档源码保持。本次未加入按关卡、帧号或像素位置修补输出的规则。

21 幅记录场景的颜色通道差由 **55 降为 18**，最大差仍为 1，完全一致整帧由 4 增至 11，每幅差异数量均未增加。但两个原本一致的单通道变得不同，完整保留：一面 1199 帧 `(96,247)` 绿色 209→208、原版 209；七面 1199 帧 `(162,471)` 红色 64→65、原版 64。改善总数不等于所有通过像素都保持通过，更不等于整作 1:1。

## 独立原生证据

- 安装环境实际 D3D9 HAL、RGBA32F 渲染目标的 240 个控制输入，包含记录到的雾范围、声明的额外范围、float32 相邻边界及负 eyeZ。各四边形 eyeZ 恒定、投影深度另设常量，排除变化插值和深度遮挡影响。上述乘法生成 bias 的融合模型 0 差异；直接除法 129 差异；用除法生成 bias 的融合模型 13 差异。输入在读取结果之前冻结，报告保留全部 Native RGB/alpha 字。
- 以自行编写的 VS2 替换固定功能顶点路径，CPU 合成矩阵、输出未饱和线性雾因子，21 份实际完整缓冲区与原固定功能输出逐字节相同。它支持候选公式，但不是反汇编恢复出的驱动内部 shader。
- 最初 `mad_sat` 的 VS2 汇编失败、随后顶点先饱和的控制产生 5,717,606 字节差，均保留，未采用；未执行的 submul 变体不算通过。

这些场景重放保留记录的直接绘制、状态和纹理，排除受控屏幕队列，不能代替原版完整游戏帧缓冲区。结论限于本机安装的 HAL，不扩大为所有显卡或实现的证明。
