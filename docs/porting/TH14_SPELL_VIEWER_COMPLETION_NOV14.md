# TH14 成功符卡录像结束与成绩保存

当前标准为可观察行为级对齐。成功收卡录像在网页查看器中原先返回标题，丢失活动录像与结束标志，前端持续等待。候选将网页托管播放的成功结算接到现有强制结束菜单，保留终态；普通游戏及非托管录像保持原有返回标题路径。

## 实际输入与复现

使用已有实际 Normal 通关存档，通过真实菜单进入灵梦 B Normal 符卡 3。测试策略只读取自机与子弹观测并提交移动／射击／低速按键，没有无敌、Bomb、经济或 RNG 写入。自然收卡于战斗回调 1,736，分数 3,179,620。原生保存录像声明 1,737 帧，1,734 字节，SHA-256 为 `02ec75303e6c0a3a5de003569aad923fb96cf677e7d493124d753d68639c64b7`。

同一文件在修复前独立进程确实返回标题而未报告结束；候选在练习 UI 开／关时均报告结束，查看器 1,737 帧／战斗回调 1,736，所测分数、power 400、graze 39 等终态保留。首轮候选测试误把战斗回调计数用作查看器帧数，失败报告保留；修正测试断言后通过，未改录像或游戏状态。

## 成功收卡成绩跨启动

保存后的新进程只读到标题，实际加载的全部 149,076 字节与原版未改指令的解密／解压结果相同。灵梦 B 与总表的符卡 3 练习捕获及尝试各 0→1，普通捕获／尝试保持 1；自机最高分记录为 317,960 个内部单位。开局次数 +1，游玩时间 +1,736，只有 13 字节变化，均位于上述字段及校验和。其他符卡计数、其他最高分、共享设置和通关／解锁字段保持。

未把所见最高分截位单独扩展为原版完整符卡计分验收。原始录像、存档、解码结果与素材留在私有证据目录，公开仅含源码、补丁及数值摘要。

机器证据见 [JSON](th14-spell-viewer-completion-nov14.json)，检查工具为 `tools/th14-check-spell-viewer-completion-nov14.mjs` 与 `tools/th14-qualify-spell-viewer-completion-nov14.py`。当前候选 Wasm `4f244ee0`，尚未进行该候选的浏览器 GPU 验收或生产替换。全符卡、其他自机／难度、浏览器持久化及整作其余缺口继续，目标保持 active。
