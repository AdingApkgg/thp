# TH14 当前六装备结局与 Staff 图形接线

当前 Chrome／ANGLE 的六种 Normal 装备均通过结局、Staff、成绩署名、录像保存菜单取消和返回标题，最终正常 Quit。18 幅稳定图像已查看：结局开场插图与日文、Staff 片头标题和动画、各机体成绩表及署名字形可见。59 个实际代码响应匹配私有测试包，游戏实现和公开运行包没有修改。全部静音。[数字与哈希](th14-current-ending-gpu-boundary-nov18.json)。

## 测试边界

此项使用专门私有构建，只在原 Application 文件后追加两个测试导出，编译一单元并核对复用 152 个对象。一个导出读取阶段和结局状态，另一个在普通游戏、工具关闭、资源和录像记录所属关卡均正确时，显式调用生产 `GameBattle::dialogue_stage_complete()`，即 MSG21 所用的完成事件。每种装备经真实菜单进入第一关，依次调用六次完成边界，由原有换关、资源线程、结局及菜单代码继续执行。

这个事件会推进游戏完成状态，因此明确不是自然六关通关。没有原始内存覆盖、分数／库存／RNG 补写或无敌保护。SDK 六种自然普通通关及 Extra 的逻辑证据另行保留；两组证据不能合称当前浏览器的完整自然通关。

最初截图在 Staff 开始后约 90 帧和成绩页淡入期间取得，流程虽通过，画面不足以证明字幕可见，原报告保留。定向复核等待 Staff 至少 600 帧、成绩页就绪再等 1.2 秒，确认文字和图形可见。结局画面抽查开场，不声称每幅插图或每一字幕逐像素核验。

公开 [测试导出源码](../../tools/th14-ending-gpu-probe-nov18.cpp.inc)和[实际浏览器驱动](../../tools/th14-check-ending-gpu-nov18.mjs)。测试导出只能附加到单独的 Emscripten 验收构建并显式加入导出列表，不能加入生产包。浏览器驱动需要 Playwright、Chrome、现成私有测试站点及 `--url=`；默认把私有产物写到 artifacts，不包含游戏数据或二进制。正常生产 Wasm `6b5e86f9…` 保持，私有 `9c11feea…` 未发布至开发站。
