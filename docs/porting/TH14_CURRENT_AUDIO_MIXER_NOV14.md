# TH14 当前混音器静音采样 · 2026-11-14

当前 TH14 的 145 个已核验提供者对象直接链接音频测试入口，实际执行 `AudioDevice`、miniaudio 和现有 18 首 OGG 的完整混音路径。在内存中累计混合 110,275,914 个立体声帧，验证 76 个音效声部、48 组原版淡出时序、三组 BGM 状态切换及全部 18 首曲目的循环边界。SDL 设备交付是明确的测试边界，全程没有真实扬声器输出，也不导出可播放 PCM 文件。

76 个声部均输出有限、范围内的非零 PCM；普通声部在其实际采样长度后归零，20／55 号持续循环，停止后为零。循环音效暂停时为零，恢复后继续输出。三组 BGM 分别覆盖暂停时游标保持、恢复、静音归零、取消静音、切换曲目及保存／恢复原曲目。48 组淡出沿用原版指令观察的音量事件，核对实际混音节点增益及淡出后零输出。

18 首曲目各通过完整长度再混合四秒，检查循环后的非零输出及游标范围。原有 OGG 解码、寻址与循环组件证据继续保留；本次新增其经过实际混音器的行为检查。资源直接读取既有原始归档和已核验 OGG 缓存，没有再次解包或复制游戏资产。

标题曲本身开头约 1.26 秒静音。首版测试错误要求首秒必须非零，失败报告保留；独立 FFmpeg 解码确认源文件的静音段后，修正为保留首秒观测并检查后续三秒，未修改音频实现或样本。

本次使用受控音频时钟和 SDL 交付边界；不宣称原版 DirectSound 最终 PCM 相同、物理延迟或完整浏览器音频时序通过。生产运行包未更换，整作继续验收。[机器摘要](th14-current-audio-mixer-nov14.json)，[构建入口](../../tools/th14-build-current-audio-mixer-nov14.py)、[混音检查](../../tools/th14-run-current-audio-mixer-nov14.mjs)。
