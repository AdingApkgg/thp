TH14 录像的管理菜单新增“下载早期移植版兼容副本”。确认录制来源后，网页下载带明确规则的新副本，原录像继续保留；用户可将新文件重新导入单独槽位播放。该入口适用于确知由早期保护版 TH14 网页移植录制的文件，不自动判断未知文件的规则。

菜单、来源说明与错误提示包含中文、英文和日文。其他作品不显示该操作。浏览器存储读取沿用现有录像操作队列；冷存储读取无需启动游戏，切换作品或关闭视图后不发布过期下载。已有规则的文件拒绝再次转换。
