# TH14 魔理沙激光异常长度保护 · 2026-11-14

`ShotCallbacksTh14.cpp` 增加圆形目标裁剪回退保护：正常交点和已有有限回退保持原行为；回退产生非有限数或超过 530 时，保留上一段有限长度，并把上一段限制在 0～530。530 来自同文件已有的“小于 512 时增长 18”规则。该候选修复阻止临时位模式变成约 `10²²` 长度的光束及碰撞区域。

这是对异常几何传播的明确行为修正，不要求重现原版未初始化栈值的每一种结果。[结构化证据](th14-beam-length-guard-nov14.json)区分源码、组件、完整普通流程与尚缺的浏览器验收。生产仍为核心 c407a169／generation 47743edb；本候选尚未构建浏览器模块或部署。

## 问题与参考

本地魔理沙 A Hard 的五面伤害窗口中，一个活动区域长度分别为约 `1.04069×10²²` 与 `1.03977×10²²`。两份测试构建初始时钟和按键相同，启动脚本 RNG 调用数相差 24；最后一次关卡／Control 键投影的首个玩法差异在五面 2389。光束区域的长度及中心坐标不同，而首个查询的目标参数相同。后一个观察构建最终通关，前一个提前结束；不能把这个观察构建变化当作生产修复或原基线等价。

公开的[魔理沙激光复现与分析](https://nylilsa.dev/bugs/th14/marisa-laser/)也说明未初始化临时值会令激光长度异常并使同一录像出现不同结果。[thprac 的处理](https://github.com/touhouworldcup/thprac/blob/master/thprac/src/thprac_th14.cpp#L699)在 45286f 处记录该值，并提供记录值、零等修正选项。本实现依据自身现有增长规则限制异常传播；没有把任何参考运行的数值写回游戏。

## 实际调用 Oracle

先在五面 2375～2378 采集约 1 MB 的实际伤害参数。原版 451430 在 16 组输入下的几何、总伤害、计分和所测区域字段一致；命中回调的返回及副作用为声明的外部边界。第一版只读观察器在该病例 75,631 回调的 27 项玩法字段与无观察基线相同。

再记录区域所有者的 ShotState／ShotSpec。9 组真实光束输入在原版 452700 的长度、伤害、计时器相关标志及普通命中计数上相同；ANM 和 cookie 服务为外部边界，原版指令字节未改。该第二版观察构建改变了启动脚本状态及后续玩法，不能继承第一版的整局不扰动结论。两项 Oracle 都未验证原版完整调用栈历史或实际 GPU 画面。

这一结果把问题指向进入裁剪回退的异常数据，而非通过补 RNG 或覆盖分数消除差异。旧记录、终态差异与未通关病例保留。

## 候选验收

- 原版有效输入 4,032 组、负值栈边缘 48 组回归通过，所测输出保持。
- 新增 30 组异常回退检查及 5 组正常交点控制通过；旧源码编译产物在同一异常检查中失败，保留负控制日志。
- 魔理沙 A Normal：107,461 次 Player 观察，六关／结局／staff／保存和新进程读回通过，分数保持 775,709,810。
- 魔理沙 B Normal：123,424 次 Player 观察，同样通过，分数保持 1,019,280,950。
- 两份成绩共 298,152 解码字节经原版解密／解压指令核对；通关与无续关计数为所选 Normal 各 1。
- 仅重编一个正常权限游戏提供者，核验复用 144 个；该文件在 TH12／13／16 宏下的新旧对象逐字节相同。
- 魔理沙 A Hard 的候选普通运行仍在五面提前结束，未计通关，也不称首次分数分歧已解决。

全部测试静音，无音频设备输出。普通长流程使用录制图形边界；这些长流程本身不证明实际 GPU 或整作完成。其后已补[浏览器短流程证据](TH14_BEAM_BROWSER_PREVIEW_NOV14.md)：魔理沙 A Normal 开局、射击、暂停／返回及静音 OGG 启动通过，完整 GPU 流程与部署仍待验收。
