# 符卡 Bonus / History 显示修复

原版 `40c4a0` 在绘制符卡背景后，还会根据第三个符卡标题动画的透明度，向内部 ASCII 绘制队列提交奖励分数和收取记录。之前 `GameBattle::draw(SceneDrawKind::Spell)` 只恢复了背景绘制，遗漏了数字提交；计分和记录数据本身仍在更新。

修复保留原版队列顺序、字库 2、内部绘制通道 1、位置与透明度：

- 奖励有效时，在 `(265, 51)` 显示至少八位数字。
- 奖励失效时，在 `(279, 51)` 使用原版字库的 `$` 对应图案。
- 在 `(360, 51)` 显示当前自机对应的收取次数／挑战次数。
- 随第三个标题动画淡入、淡出；动画句柄过期时清零，不留下数字。

仍使用共用 SDL3 / WebGL2 渲染器。游戏更新、计分、录像输入和资源格式没有改动。
