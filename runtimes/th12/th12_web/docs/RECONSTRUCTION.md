状态：本体实现和本地发布验收已完成，当前日文 1.00a。手机真机体验仍需用户测试；公网隧道启动被自动审批服务故障阻塞，未宣称已部署成功。

## 实现与基准

原版 EXE SHA-256：`2978b17f6184d100d249d4311348dd30c5c32ec75c014b667a525b797d3d8813`。以实际机器码、资源、函数调用次序、x87 舍入和原版录像为行为依据，恢复具名 C++ 管理器及脚本解释器。

平台基准由 `config/final-baseline.json` 保存：TH08 3.4.1-sdl3、TH10 3.5.1-sdl3、TH09 b6e1724a546540054415b15e。直接编译共享的 Renderer、GraphicsState、Shaders、FrameCadence 及 TouchController；发布运行时不执行原版 EXE 或 x86 转译，不使用 D3D8/9 设备适配层。
