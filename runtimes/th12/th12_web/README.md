# 东方地灵殿 1.00a · C++ / SDL3 网页版

日文 1.00a 的完整游戏本体已接入具名 C++ 实现，包括六种自机、四种常规难度、六面、Extra、菜单、对话、结局、Staff Roll、音效、OGG 音乐、存档和原版格式录像。

运行路径为 C++ → WebAssembly → SDL3 / WebGL2，直接使用永夜抄、风神录及花映塚最终版的工作区共享渲染器与帧调度。前端沿用最终共用启动器，包含连续触控、布局设置、暂停、资源缓存、存档与录像管理。生产运行不执行原版 EXE，也不包含 x86 转译或 D3D8/9 设备适配层。

## 游玩

双击本目录的 **启动地灵殿网页版.cmd**，在浏览器打开 `http://127.0.0.1:8113/`。保持启动窗口开启；资源首次下载后可由浏览器缓存。公网部署地址与构建校验记录位于 `artifacts/sdl-release/verification/deployment.json`，临时隧道地址重新启动后可能变化。

- 键盘：方向键移动，Z 射击／确认，X Bomb／取消，Shift 低速，Esc 暂停。
- 手机：通过最终版共用触控布局操作，支持连续拖动、低速、射击开关、B 和暂停按钮。
- 存档、配置和录像保存在每位玩家自己的浏览器 IndexedDB，不上传到主机。原版录像使用 `.rpy`；连续触控录像使用扩展 `.rpyx`。
- 日文原版始终是逻辑及资源回退基准。由工作区 `th11/portable/build.mjs` 构建、接入 eagler-touhou Launcher 的版本可选用从 thcrap 补丁编制的简体中文和英文语言包；本地附带的汉化 EXE／`th11c.dat` 不参与编包。独立启动脚本的语言功能不在此范围内。

## 验证与边界

本轮修正了六面特定符卡的无敌减伤状态读取，消除第 99,450 帧开始的血量和录像偏差。现场重演六面／Extra 的最终分数均与原录像头一致。

- 完整模块回归：121 项通过、0 项失败；长流程另行执行。
- 原版行为证据覆盖六面录像 100,672 帧、Extra 43,256 帧、四份演示 18,049 帧。六面采用已验证原版前缀、新旧核心逐字段等价及连续原版尾段组成的完整证据链，具体范围与哈希见验收文档。
- 实际 SDL3 / WebGL2 浏览器完成六面及 Extra 回放，以及 56 个音效编号、18 首 OGG、42 组对话入口、结局和持久化检查。
- 最终启动器的手机尺寸布局、音频解锁、连续触控、暂停恢复、退出重开、录像导入导出、同来源更新及离线启动已检查。

这些是固定样本及桌面浏览器验证，不代表穷举所有输入或承诺无 bug、所有手机零掉帧。手机真机体验需通过测试入口验证；发现问题时保留录像、机体／难度、出错位置及设备浏览器信息。
